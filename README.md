<p align="center"><strong>Личный SQL-редактор и аналитическая доска.</strong><br />ClickHouse · Trino · SQLite · Apache-2.0</p>

[Выпуски](https://github.com/Manannikov-Nikita/miracle/releases) · [Установка](docs/local-installation.md) · [Руководство](docs/usage.md) · [Что проверено](docs/release-validation.md)

Miracle работает на вашем компьютере и открывается в браузере. Подключитесь к ClickHouse или Trino, выполните SQL и соберите таблицы, графики и заметки на доске. Каждая папка запуска становится отдельным проектом; SQL-документы, снимки, доски и чаты агентов сохраняются в её `.miracle/`. Аккаунт, регистрация, PostgreSQL и Docker для запуска не нужны.

**English:** Miracle is a personal local SQL workspace for ClickHouse and Trino. Run queries and turn result snapshots into charts, tables, and notes. It serves a Russian-language browser interface on loopback, stores its workspace in SQLite, and ships with its own runtime.

**Вышла 0.4.0:** обновлённое оформление, свободные стрелки с настройкой изгиба и подписью на линии, непрерывная прокрутка доски и понятные сообщения об ошибках. Просмотр, выделение и открытие свойств не создают сохранений и конфликтов. Для перехода с 0.2.0 и 0.2.1 повторите установку по [инструкции обновления и переноса](docs/local-installation.md#обновление-с-020-и-021): прежние данные сохраняются, а браузерные SQL-черновики нужно импортировать на исходном адресе.

## Возможности

| Область   | Что можно делать                                                                                                                                                              |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SQL       | Несколько .sql-вкладок, автодополнение, форматирование, запуск выделения или запроса под курсором, запуск по диапазону дат с повторами и прогрессом, импорт и экспорт файлов. |
| Таблицы   | Форматы колонок, условное оформление, фильтры, итоги и сводные — [подробнее](docs/table-capabilities.md).                                                                     |
| Графики   | Вертикальные и горизонтальные столбцы, линейный, площадной и точечный графики; оси, серии, легенда и форматы чисел.                                                           |
| Доска     | Снимки результатов, Markdown, заметки и свободные стрелки с изгибом и подписью; масштабирование, отмена и автосохранение правок.                                                                        |
| Агенты    | Чаты с локальными Codex CLI и Claude CLI, файлы через `@`, выбранные блоки доски как контекст, компактная история действий, разрешения и остановка.       |
| Проекты   | Отдельная `.miracle/` в папке проекта, независимые процессы и порты, восстановление документов и чатов из копии.                                                              |
| Источники | ClickHouse и Trino; дерево схем с ленивой загрузкой, общий кеш поиска и подсказок; HTTPS и собственный CA для обоих движков, клиентские сертификаты для ClickHouse.           |

Снимок хранит исходный SQL и контекст подключения. Его можно обновить независимо от открытого файла; при ошибке предыдущий результат остаётся. Изменения агента сразу появляются в редакторе и на доске; при одновременных правках сохраняется локальный черновик. Кнопки SQL и доски независимо показывают или скрывают свою область.

## Установка

Готовый установщик и архивы доступны в [выпуске 0.4.0](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.4.0). Команда ниже устанавливает последний опубликованный выпуск.

macOS, Linux и Windows через терминал WSL 2:

```sh
curl -fsSL https://github.com/Manannikov-Nikita/miracle/releases/latest/download/install.sh | sh
~/.local/bin/miracle
```

Начиная с установщика 0.3.1, если каталог команды отсутствует в PATH, он предлагает добавить его в настройки вашей оболочки. Подтвердите изменение и откройте новый терминал либо выполните напечатанную команду для текущего окна.

Если после установки появляется `miracle: command not found`, для стандартной установки в zsh или Bash выполните:

```sh
export PATH="$HOME/.local/bin:$PATH"
miracle --version
```

Для постоянной настройки и других оболочек см. [как исправить PATH](docs/local-installation.md#если-терминал-пишет-miracle-command-not-found). До настройки работают команды по полному пути: `~/.local/bin/miracle start` и `~/.local/bin/miracle stop`.

На Windows сначала нужен [WSL 2 с Linux](https://learn.microsoft.com/en-us/windows/wsl/install). Команды установки и запуска выполняются в его терминале; напечатанный адрес откройте в браузере Windows. [Полная инструкция](docs/local-installation.md) содержит требования к WSL, ручную установку, обновление и резервное копирование.

Комплект содержит Node.js; устанавливать runtime, npm или Git отдельно не нужно. Четыре сборки: macOS Intel/Apple Silicon и GNU/Linux x64/ARM64. В WSL 2 используется Linux-сборка. ClickHouse или Trino подключаются отдельно.

После установки запускайте `miracle` из папки проекта. Команда запускает сервис и печатает `http://127.0.0.1:PORT` со свободным портом ОС. На macOS/Linux команда также открывает браузер; в WSL перейдите по напечатанному адресу в браузере Windows. Рабочая область открывается сразу, без входа.

```sh
cd ~/projects/analysis
miracle status
miracle stop
miracle open --project-dir ~/projects/other-analysis
# Фиксированный порт при необходимости:
miracle start --port 3002
```

Интерфейс предназначен для настольного браузера. Приложение рассчитано на одного человека на одном компьютере. Повторное открытие проекта использует его работающий процесс. `--data-dir` / `MIRACLE_DATA_DIR` меняет только место хранения, сохраняя папку проекта как cwd агента. Автозапуск при входе в ОС не включается.

## Обновление

**С 0.2.0 и 0.2.1:** команды `update` в них нет. Сначала сохраните резервную копию, затем повторно запустите установщик по [пошаговой инструкции](docs/local-installation.md#обновление-с-020-и-021). Он обновит программу до 0.4.0 с сохранением прежних данных. После установки откройте старое хранилище на прежнем адресе и порту для импорта браузерных SQL-черновиков. Новая `.miracle/` в другой папке не содержит старую глобальную рабочую область автоматически.

**В установленной 0.3.0 и последующих версиях:**

```sh
miracle update --check
miracle update
```

Команда проверяет официальный выпуск и обновляет установленную программу. Перед обновлением сохраните копии остановленных проектов.

## Сохранность данных

SQLite и ключ шифрования находятся в `PROJECT/.miracle/` отдельно от кода программы. Команда `miracle backup DIRECTORY` сохраняет их вместе с SQL-документами, досками, профилями и чатами; перед копированием остановите проект. Обычные файлы проекта и домашние настройки/авторизация провайдера не входят в копию.

Старый глобальный `data/` автоматически не перемещается. Чтобы сохранить браузерные SQL-черновики, сначала откройте прежние данные на исходном адресе и порту, дождитесь импорта, затем перенесите остановленную рабочую область через backup/restore. [Пошаговая инструкция](docs/local-installation.md#перенос-существующей-рабочей-области). После переноса проверьте и подтвердите команды профилей локально. PostgreSQL-данные версии 0.1.0 не импортируются и не удаляются.
