<p align="center"><strong>Личный SQL-редактор и аналитическая доска.</strong><br />ClickHouse · Trino · SQLite · Apache-2.0</p>

[Выпуски](https://github.com/Manannikov-Nikita/miracle/releases) · [Установка](docs/local-installation.md) · [Руководство](docs/usage.md) · [Что проверено](docs/release-validation.md)

Miracle работает на вашем компьютере и открывается в браузере. Подключитесь к ClickHouse или Trino, выполните SQL и соберите таблицы, графики и заметки на доске. Каждая папка запуска становится отдельным проектом; SQL-документы, снимки, доски и чаты агентов сохраняются в её `.miracle/`. Аккаунт, регистрация, PostgreSQL и Docker для запуска не нужны.

**English:** Miracle is a personal local SQL workspace for ClickHouse and Trino. Run queries and turn result snapshots into charts, tables, and notes. It serves a Russian-language browser interface on loopback, stores its workspace in SQLite, and ships with its own runtime.

Проекты и локальные агенты описывают текущую исходную версию и ещё не опубликованы в релизе 0.2.1. Для существующей установки сначала прочитайте [порядок переноса](docs/local-installation.md#перенос-существующей-рабочей-области).

## Возможности

| Область   | Что можно делать                                                                                                                                                              |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SQL       | Несколько .sql-вкладок, автодополнение, форматирование, запуск выделения или запроса под курсором, запуск по диапазону дат с повторами и прогрессом, импорт и экспорт файлов. |
| Таблицы   | Форматы колонок, условное оформление, фильтры, итоги и сводные — [подробнее](docs/table-capabilities.md).                                                                     |
| Графики   | Вертикальные и горизонтальные столбцы, линейный, площадной и точечный графики; оси, серии, легенда и форматы чисел.                                                           |
| Доска     | Снимки результатов, Markdown, заметки и связи; выравнивание, масштабирование, отмена и автосохранение.                                                                        |
| Агенты    | Чаты с локальными Codex CLI и Claude CLI, работа с файлами проекта и инструментами SQL/доски, поток действий, разрешения и остановка. Провайдер авторизуется своим CLI.       |
| Проекты   | Отдельная `.miracle/` в папке проекта, независимые процессы и порты, восстановление документов и чатов из копии.                                                              |
| Источники | ClickHouse и Trino; дерево схем с ленивой загрузкой, общий кеш поиска и подсказок; HTTPS и собственный CA для обоих движков, клиентские сертификаты для ClickHouse.           |

Снимок хранит исходный SQL и контекст подключения. Его можно обновить независимо от открытого файла; при ошибке предыдущий результат остаётся. Проверка версий защищает доску от случайной перезаписи из другой вкладки.

## Установка

Готовый установщик и архивы доступны в [выпуске 0.2.1](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.2.1).

macOS, Linux и Windows через терминал WSL 2:

```sh
curl -fsSL https://github.com/Manannikov-Nikita/miracle/releases/latest/download/install.sh | sh
~/.local/bin/miracle
```

На Windows сначала нужен [WSL 2 с Linux](https://learn.microsoft.com/en-us/windows/wsl/install). Команды установки и запуска выполняются в его терминале; напечатанный адрес откройте в браузере Windows. [Полная инструкция](docs/local-installation.md) содержит требования к WSL, ручную установку, обновление и резервное копирование.

Комплект содержит Node.js; устанавливать runtime, npm или Git отдельно не нужно. Четыре сборки: macOS Intel/Apple Silicon и GNU/Linux x64/ARM64. В WSL 2 используется Linux-сборка. ClickHouse или Trino подключаются отдельно.

В исходной версии запустите `miracle` из папки проекта. Команда запускает сервис и печатает `http://127.0.0.1:PORT` со свободным портом ОС. На macOS/Linux команда также открывает браузер; в WSL перейдите по напечатанному адресу в браузере Windows. Рабочая область открывается сразу, без входа.

```sh
cd ~/projects/analysis
miracle status
miracle stop
miracle open --project-dir ~/projects/other-analysis
# Фиксированный порт при необходимости:
miracle start --port 3002
```

Приложение предназначено для одного человека на одном компьютере. Повторное открытие проекта использует его работающий процесс. `--data-dir` / `MIRACLE_DATA_DIR` меняет только место хранения, сохраняя папку проекта как cwd агента. Автозапуск при входе в ОС не включается.

## Сохранность данных

SQLite и ключ шифрования находятся в `PROJECT/.miracle/` отдельно от кода программы. Команда `miracle backup DIRECTORY` сохраняет их вместе с SQL-документами, досками, профилями и чатами; перед копированием остановите проект. Обычные файлы проекта и домашние настройки/авторизация провайдера не входят в копию.

Старый глобальный `data/` автоматически не перемещается. Чтобы сохранить браузерные SQL-черновики, сначала откройте прежние данные на исходном адресе и порту, дождитесь импорта, затем перенесите остановленную рабочую область через backup/restore. [Пошаговая инструкция](docs/local-installation.md#перенос-существующей-рабочей-области). После переноса проверьте и подтвердите команды профилей локально. PostgreSQL-данные версии 0.1.0 не импортируются и не удаляются.
