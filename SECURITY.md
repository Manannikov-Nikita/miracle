# Безопасность

Сообщайте об уязвимостях через [приватный отчёт GitHub](https://github.com/Manannikov-Nikita/miracle/security/advisories/new). Не публикуйте пароли, токены, ключи, дампы и эксплуатационные детали в открытых issues.

Укажите версию, способ установки, шаги на синтетических данных, ожидаемый/фактический результат и возможное влияние. У проекта нет гарантированного срока ответа или долгосрочного обслуживания старых версий.

## Локальная модель

Miracle предназначен для одного человека на одном компьютере и слушает 127.0.0.1. Аккаунтов и совместного доступа нет. Проверки Host/Origin, локальная сессия и CSRF защищают API от посторонних веб-страниц. Не публикуйте сервис через reverse proxy; внешний доступ не является поддерживаемым сценарием.

Используйте отдельные учётные записи ClickHouse/Trino с правами чтения. Проверка SQL дополняет права СУБД.

Пароли источников и приватные TLS-материалы зашифрованы. Для восстановления нужны SQLite и соответствующий ключ. Резервные копии содержат секреты; храните их приватно. [Копирование и восстановление](docs/local-installation.md#резервное-копирование-и-восстановление).

Релизные установщики проверяют SHA-256 архивов. Проверка контрольной суммы обнаруживает повреждение; доверие к содержимому зависит от официального GitHub Release и его канала доставки.
