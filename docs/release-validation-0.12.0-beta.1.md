## Локальные проверки

- Node 24.22.2, **204 файла / 2 609 тестов**, все прошли. TypeScript и production build прошли; сохраняются прежние предупреждения Vite и React `act`.
- Проверены обязательный `--beta` до скачивания/изменения установки, отсутствие opt-in по умолчанию, выбор стабильных и beta-версий, порядковое сравнение beta.2/beta.10 и beta/stable, запрет downgrade, некорректные версии, безопасный launcher с пустым PATH, ограничения пагинации GitHub API и неизменность существующего релиза.
- Независимое ревью beta-канала завершено без открытых замечаний. Публикация beta использует `--prerelease --latest=false`.
- Архивы macOS ARM64, Linux ARM64 и Linux x64 прошли checksum и расширенную установку с `--beta`, XLSX, цепочку внешний запрос → датасет → JOIN с CSV → второй датасет → reinstall/backup/restore. Внешняя сеть была запрещена: macOS `sandbox-exec` с доступом только к loopback fixtures, Linux Docker `--network none`; x64 под эмуляцией на ARM64.
- Реальная установка опубликованной 0.11.0 обновлена beta-установщиком в режимах project/custom: миграция 8 → 9, сохранение всех данных и резервных копий. Запуск без флага, ошибка скачивания и неверная checksum сохраняют прежние PID и данные. Обычный updater в бете не понижает её до стабильной 0.11.0.

Логи: `.local/release-0.12.0-beta.1/`; исходные локальные архивы: `/private/tmp/miracle012-beta-native/<target>/`. GitHub Actions повторяет тесты, сборку, установку и обновление с 0.11.0 на всех трёх платформах перед публикацией тега.

## Установка и ограничения

```sh
curl -fsSL https://github.com/Manannikov-Nikita/miracle/releases/download/v0.12.0-beta.1/install.sh | sh -s -- --beta
```

После перехода: `miracle update --beta --check` и `miracle update --beta`. Установщик стабильной 0.11.0 по адресу `latest/download/install.sh` не поддерживает новый флаг — первый переход использует URL выше.

Перед первым открытием существующего проекта нужна резервная копия для возможного возврата к 0.11.0: старый бинарник не читает схему 9. Реальные корпоративные коннекторы, отдельный WSL-хост и настоящий Claude CLI заново не проверялись.
