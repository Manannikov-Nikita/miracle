# Shapes Implementation Plan

> **For agentic workers:** Use subagent-driven-development for independent file scopes; root integrates and verifies. No commits or runtime/data deletion beyond the owned disposable test runtime.

**Goal:** Add seven editable, styled geometric shapes to boards and presentations.

**Architecture:** Existing artifact node with `data.kind = "shape"`, `data.text` and validated `data.shape`. SVG geometry and HTML text; shared renderer serves canvas, slide thumbnails and show.

**Tech Stack:** React, TypeScript, SVG, existing XYFlow/Radix/Zod/Vitest.

**Spec:** `docs/superpowers/specs/2026-11-06-shapes-design.md`

## Global Constraints

- Continue authorized dirty `codex/release-0.8.0` workspace. Preserve earlier changes and user project data. No push, commit or deployment.
- Use CodeGraph first for code lookup. Node 24 at `.local/node24/bin`; no new dependencies.
- Shapes: `rectangle | rounded-rectangle | ellipse | triangle | diamond | hexagon | arrow`.
- `ShapeSpec` fields: required `type`; optional `fill` (#RRGGBB or transparent), `stroke` (#RRGGBB), `strokeWidth` (0–12), `strokeStyle` (solid/dashed/dotted), `opacity` (0–1), `cornerRadius` (0–50, percent), `textColor` (#RRGGBB), `fontSize` (8–144), `fontFamily` (sans/serif/mono), `bold`, `italic`, `underline`, `textAlign` (left/center/right), `verticalAlign` (top/middle/bottom).
- Shared `src/shared/shapes.ts` exports ShapeKind, ShapeSpec, SHAPE_OPTIONS ({type,label}), shapeSpecSchema, resolveShape(spec?: ShapeSpec): Required<ShapeSpec>.
- Defaults: rectangle, fill #dbeafe, stroke #3b82f6, width 2, solid, opacity 1, cornerRadius 16 only for rounded-rectangle (0 otherwise), text #172033, font 24 sans, styles false, center/middle.
- Keep shape text plain text and avoid raw SVG/HTML. `data.text` retains existing 200000-character limit. Existing 200-node document limit applies.

## Review Focus

- Imported/copied/agent-written shape settings must survive server validation, save and reload.
- Text entry must not trigger canvas delete, paste or undo shortcuts; read-only shapes stay immutable.
- No artifact container or hidden text in slide previews/show; small resized figures remain usable.
- Node drag must not accidentally edit text; typing and selection inside inline editor must not drag node.
- Shape insertion captures its current document/slide, preserves previous dirty work, and respects locks.
