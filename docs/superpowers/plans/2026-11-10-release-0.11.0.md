# Miracle 0.11.0 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement the independent tasks and verify their integration.

**Goal:** Собрать проверенный выпуск 0.11.0 с пятью исходными изменениями, копированием таблиц в Markdown и favicon.

**Architecture:** Существующие React/CodeMirror/Fastify/SQLite компоненты расширяются без смены стека. Независимые области реализуются параллельно с согласованным владением общими файлами.

**Tech Stack:** TypeScript, React, React Flow, CodeMirror, Fastify, SQLite, Node 24.22.2, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-10-release-0.11.0-design.md`

## Global Constraints

- Node 24.22.2; UI only desktop.
- Не трогать `miracle-product-video/`, пользовательские проекты, ключи и `.miracle` пользовательских проектов.
- Сохранять черновики, проверку TLS, ограничения файлового API и совместимость старых досок.
- Первоначальный этап локальной сборки без публикации завершён; после проверки пользователь разрешил публикацию 0.11.0 на GitHub.
- UI проверяется через @Browser. Публикация выполняется отдельным этапом после локальных проверок; её фактический результат фиксируется в отчёте о выпуске.

## Review Focus

- Большие/невалидные картинки, копия блока, backup/restore и обновление старого проекта.
- YAML с `_`, `$`, ссылками, CRLF/BOM и незакрытым разделителем.
- Коллизии имён, симлинки, блокировки агента и запоздавший ответ загрузки перемещённого файла.
- Drag за пределы панели, Escape, отпускание вне цели, масштаб и прокрутка.
- Недоверенный TLS и ошибка ручного PEM при включённом системном доверии.
