# Проверка редизайна чата агента

Дата: 31 октября 2026. Стенд: `http://127.0.0.1:50264/`, проект `.local/demo-project`, реальная история Codex и данные NYC Taxi в ClickHouse. По уточнению пользователя приёмка предназначена для ПК; проверку мобильной версии прекратили, временный размер окна сброшен.

## Результат

- `npm test`: 738 тестов, 60 файлов — успешно.
- `npm run build`: успешно; включает оба TypeScript-проекта. Сохраняется прежнее предупреждение Vite о размере основного bundle.
- `git diff --check`: успешно.
- Независимый обзор обнаружил потерю фокуса после диалогов, скрытие имён авторов от экранного диктора и смещение нижней границы переписки при росте поля ввода. Все три замечания исправлены; поведенческие проверки фокуса и изменения высоты сначала воспроизводили ошибки, затем прошли.

## Проверено в браузере на ПК

- Шесть ходов реальной истории отображают шесть строк действий; фазовые события инструментов не представлены отдельными сообщениями.
- Журнал открывается поверх переписки внутри панели. Все события доступны; развёрнутые исходные данные прокручиваются в блоке ограниченной высоты.
- Исправленная ошибка инструмента не выдаётся за провал задачи: завершённый ход показывает «Готово с замечаниями».
- Создание пустого разговора не запускает CLI и не создаёт серверный чат до отправки; старая история доступна через меню.
- Поиск истории, пустой результат поиска и возврат к сохранённому разговору работают.
- Настройки открываются из меню внутри поля ввода. Escape закрывает диалог, оставляет чат открытым и возвращает фокус в поле ввода.
- Многострочный неотправленный черновик увеличивает поле до 180 px; расстояние от переписки до нижней границы остаётся около нуля. Проверочный черновик очищен.
- Прежняя рабочая раскладка сохранена. Сервер и задачи не перезапускались и не отменялись. Изменения клиента доступны на прежнем адресе.

Снимок результата: `.local/demo-project/agent-chat-redesign.jpg`.

## Наблюдение вне изменений

При загрузке большой старой истории возникает временный индикатор переподключения. Существующий сервер SSE закрывает поток при заполнении буфера записи, клиент догружает историю порциями с интервалом 1,5 с. Журнал подтвердил продвижение курсора до конца; примерно через 18 секунд индикатор исчезает и поток остаётся подключённым. Это поведение предшествует редизайну; протокол событий в этой работе не менялся.

Последующее исправление от 31 октября устраняет эту причину закрытия SSE: поток продолжает доставку после освобождения буфера. См. `2026-10-31-agent-live-sync-verification.md`.

Информационная подпись под полем ввода убрана. Объяснение для ещё не настроенного профиля показывается только при необходимости.
