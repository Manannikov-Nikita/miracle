# Оформление стандартных графиков

Пользователь просит скрывать оси, добавлять значения к столбцам/точкам и управлять цветами. Дополнение: вспомогательные линии сетки должны отключаться отдельно.

Расширяем существующий раздел «Оформление», сохраняя привычный вид панели. Независимые переключатели осей X/Y, сетки и подписей значений. Для столбцов — автоматическое расположение, снаружи или внутри; для линий, областей и scatter — возле точки. Формат подписей соответствует уже выбранному формату чисел. В накоплении показываем значение сегмента. Перекрывающиеся подписи скрываются.

Цвета: четыре готовые палитры и индивидуальный цвет каждой серии через образец/HEX. Цвет привязан к идентификатору метрики, полю разбивки и значению группы, поэтому перестановка строк не переносит индивидуальный цвет на другую серию. Можно вернуть цвет серии или всех серий к палитре. Список групп загружается из сохранённого снимка только при раскрытии цветов; SQL не запускается.

Это выбранные при реализации детали, а не дополнительные требования пользователя. Вместо отдельного редактора оформления используются существующие настройки блока. Свойства необязательные: старые графики выглядят как раньше. Общая схема принимает настройки при сохранении, копировании и вставке между досками. Кастомные графики с собственным JavaScript остаются под управлением их исходников.

План: (1) типы, валидация, стабильные ключи и ECharts options; (2) компактные контролы, ошибки загрузки цветов; (3) проверки реального ECharts, UI и сериализации; (4) полная проверка, сборка, демонстрационная доска на стенде3060.
