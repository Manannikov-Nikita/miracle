# Колор-пикер и сохранённые цвета Miracle

Пользователь запросил собственный колор-пикер в стиле Miracle, с оглядкой на Figma, и настройки сохранённых цветов внизу левого навбара.

## Решение

Общий компактный popover для всех существующих свободных цветов: текст, заливка и обводка фигур, серии графиков, фон слайдов. Тёмные поверхности, тонкие границы, мятный акцент, текущие шрифты и иконки Miracle. Поле насыщенности/яркости, полоса оттенка, точный ввод HEX/RGB/HSL, предпросмотр и пипетка при поддержке браузером. Сохранённые цвета доступны из каждого пикера; текущий цвет можно добавить кнопкой +. Базовые образцы отдельны от пользовательской палитры.

Шестерёнка в нижней группе навбара открывает «Настройки» с разделом «Сохранённые цвета». Цвет имеет имя и HEX; пользователь добавляет, редактирует, перемещает и удаляет цвета. Изменение образца не перекрашивает уже оформленные объекты. Пустая палитра объясняет, как добавить первый цвет.

Решения исполнителя: палитра хранится для текущего origin Miracle в браузере (localStorage; проекты на разных портах имеют отдельные палитры), синхронизируется между вкладками; максимум 64 образца; сохранение немедленное с видимой ошибкой при отказе хранилища. Цвета сохраняются в существующем формате #RRGGBB, без изменения серверного API. «Без заливки» остаётся доступно для фигур. Существующая непрозрачность фигуры остаётся отдельной настройкой.

## Подходы

Выбран общий React-компонент поверх существующих UI-примитивов: единое поведение во всех редакторах и точное соответствие теме. Системный input=color не позволяет оформить панель. Полный аналог Figma с градиентами, стилями-ссылками и альфой требует отдельной модели документов и не нужен для этой задачи.

## Поведение и проверка

Панель помещается в экран, открывается рядом с образцом и возвращает фокус на него при Escape. Поле и ползунки доступны с клавиатуры, ввод промежуточных значений не портит сохранённый цвет. Перетаскивание не запускает горячие клавиши/жесты доски. Серый/чёрный цвет сохраняет выбранный оттенок при регулировке. Пипетка не отображается без поддержки; отмена не меняет цвет. Безопасная загрузка повреждённой палитры, отсутствие дубликатов по HEX, работа при запрете localStorage, тесты преобразований и реальных UI-сценариев; проверка на тестовом стенде без изменения пользовательских объектов.
