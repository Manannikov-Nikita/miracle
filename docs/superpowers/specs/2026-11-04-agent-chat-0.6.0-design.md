# Чат агента — подготовка 0.6.0

Пользователь запросил отправку изображений агенту как референсов, переключатель автоапрува и компактные согласования под ответом модели. После реализации нужен работающий локальный стенд для следующего раунда требований; публикация релиза не запрошена.

## Поведение

- До четырёх PNG/JPEG/GIF/WebP, до 5 MiB каждое: выбор файла, вставка из буфера и перенос в поле сообщения. Миниатюры можно удалить до отправки; сообщение может состоять только из изображений. Черновики и вложения принадлежат своему чату, сохраняются при ошибке и очищаются после успешной отправки. Сохранённые изображения доступны в истории.
- Автоапрув — явный переключатель конкретного чата, исходно выключен. Настройка сохраняется на сервере, действует без открытой вкладки; включение разрешает и уже ожидающее действие. Отключение возвращает ручные согласования будущих запросов. История показывает автоматические решения.
- Ответ модели остаётся главным содержимым. Инструменты и апрувы располагаются ниже в компактных приглушённых строках. Подробности изначально закрыты, ручные кнопки решения доступны сразу. События инструментов/согласований не прокручивают читаемый текст.

## Выбор реализации

Продолжаем существующий React/Fastify чат и нативные адаптеры Codex/Claude. Изображения передаются структурированно, не через строковые пути проекта. Предпочтение автоапрува хранится на сервере, поскольку клиентская автоматизация перестала бы работать при закрытии вкладки. Отдельная большая карточка согласования заменяется строкой с раскрытием, сохраняя доступ к аргументам.

Решения о лимитах и размещении элементов приняты разработчиком в пределах запроса. Существующие проверки доверия профилю остаются обязательными. Проверяем транспорт обоих провайдеров, сохранение/повтор отправки, переключение режимов и реальный браузерный интерфейс.
