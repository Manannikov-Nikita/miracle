# Буфер обмена блоков доски

Запрос: Cmd+C и Cmd+V для блоков, включая перенос копий между досками.

Используем нативные события copy/paste в области доски, чтобы сочетания клавиш и системный буфер работали без отдельного запроса разрешения. Пакет с версией, идентификаторами проекта/доски и снимком выделенных блоков передаётся в собственном MIME и узнаваемом text/plain. Пакет проверяется общей с сервером схемой документа. Обычный текст и ввод внутри редакторов не перехватываются.

При копировании фиксируем содержимое и только внутренние связи группы. Каждая вставка создаёт новые ID блоков и связей, независимые настройки и один шаг истории. Снимки результатов остаются общими неизменяемыми ссылками внутри проекта; SQL не выполняется. На исходной доске используем смещение, на другой — центр видимой области; повторные вставки смещаются. После вставки выделены новые блоки.

Внутренний буфер в памяти отклонён: он терялся бы при перезагрузке и не давал обычной работы между вкладками. Асинхронный Clipboard API не нужен при нативном событии. Перенос между разными проектами не входит в запрос: ссылки на результаты и подключения принадлежат проекту, поэтому такой пакет отклоняется с понятным сообщением.

Проверка: поведенческие тесты copy/paste и сохранения, обе доски и история, новые ID и связи, исходные снимки, повторная вставка, текстовые редакторы, чужие/некорректные данные и лимиты. Затем сборка, полный прогон тестов и реальные Cmd+C/Cmd+V на локальном стенде.
