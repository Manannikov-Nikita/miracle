# Git рядом с подключением

Пользователь выбрал локальные действия и статус worktree: ветка, изменения, diff, создание и переключение веток, коммит выбранных файлов, список worktree. Компактная кнопка в строке подключения открывает окно Git в существующем стиле Miracle. В текстовом редакторе кнопка доступна рядом с путём файла.

Используем системный Git через execFile с отдельными аргументами и текущим projectRoot; новые зависимости не нужны. Репозиторий верхнего уровня, внутри которого находится проект, можно показывать, но изменения доступны только при запуске Miracle из корня рабочего дерева. Файлы .miracle и каталог runtime data исключаются из выбора. Git не управляет документами из SQLite: это явно объясняется в окне. Нет fetch/pull/push, reset, удаления веток или создания worktree.

Сравнение вариантов: один индикатор не покрывает выбранные действия; отдельная большая Git-панель перегружает раскладку; компактная кнопка и диалог позволяют сохранить место для редактора. Выбранный набор согласован пользователем; организация окна — решение исполнителя.

Переключение веток допускается только без изменений на диске и без несохранённых файлов редактора; активный агент блокирует операции. Чистые открытые файлы после переключения перечитываются, исчезнувшие сохраняются как черновики. Коммит включает текущее содержимое только выбранных файлов и сохраняет посторонние staged changes. Ревизия состояния защищает от действий по устаревшему списку. Никаких операций над рабочим репозиторием разработки при QA: изменения проверяются в disposable fixture.
