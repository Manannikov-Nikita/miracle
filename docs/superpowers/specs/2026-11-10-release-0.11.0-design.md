# Miracle 0.11.0

Запрошены пять изменений: изображения на досках и слайдах, корректный YAML front matter в Markdown, создание папок и перенос файлов в редакторе, видимый поверх панелей лёгкий эскиз при переносе объектов, автоматический поиск доверенных сертификатов с ручным вариантом.

## Решения реализации

- Изображение — самостоятельный блок доски, доступный также на слайде и в режиме показа. Загрузка из файла, перетаскиванием и вставкой из буфера; PNG/JPEG/GIF/WebP. Бинарные данные хранятся отдельно от JSON доски, доступны только через локальный API проекта, сохраняются при backup/restore. Размер и тип проверяет сервер. Копирование блоков сохраняет ссылку на неизменяемое изображение.
- Начальный блок между строками `---` воспринимается как метаданные, а не Markdown. Исходный текст остаётся видимым и редактируемым, включая имена навыков, подчёркивания, формулы и ссылки; обычная разметка после блока работает прежним образом. Незакрытый начальный блок также сохраняется как исходный текст.
- Дерево проекта позволяет создать папку и перенести файл в папку или корень. Перезапись существующего файла запрещена; внутренние каталоги и симлинки не становятся обходом ограничений проекта. Открытый редактор сохраняет черновик и переключает путь после успешного перемещения. Перетаскивание папок не входит в этот выпуск.
- При переносе между панелями отображается полупрозрачный контур поверх интерфейса через portal. Он не перехватывает указатель и не обрезается границами панелей. Существующие правила копирования/перемещения и отмены сохраняются.
- HTTPS автоматически использует доверенные CA Node и ОС. Ручной PEM остаётся доступным для конкретного подключения. Проверка имени сервера и TLS не отключается; сертификаты, полученные от непроверенного сервера, автоматически доверенными не становятся.

## Проверка и выпуск

Node 24.22.2, полный набор Vitest, TypeScript, production build, нативный архив macOS ARM64, установка и обновление с 0.10.0. UI проверяется только на desktop во встроенном Browser. Изменения не затрагивают `miracle-product-video/`, пользовательские проекты и секреты. Первоначальный этап локальной сборки без публикации завершён. После проверки пользователь разрешил публикацию 0.11.0 на GitHub; результат публикации фиксируется отдельно в отчёте о выпуске.

## Дополнения пользователя

- Копирование всей таблицы в буфер как Markdown: в SQL-результатах и на доске, с заголовками и экранированием данных. На доске учитываются фильтры, сортировка, видимые столбцы и формат отображения; при растущем результате SQL копируется актуальный снимок.
- Favicon использует существующий логотип Miracle.

## Уточнение навигации по дереву

По замечанию пользователя кнопка «Корень проекта» удаляется. Корень — состояние без выбранного элемента дерева: щелчок по свободному месту или Escape снимает выбор, сохраняя открытый редактор. Создание использует выбранную папку (или родительскую папку выбранного файла), а без выбора — корень. Файл можно перенести в корень, отпустив в свободной области дерева; подсказка появляется только во время переноса и не сдвигает строки.

## Вставка изображений из буфера

После щелчка по доске или слайду ⌘V / Ctrl+V вставляет изображение в активную область. Поддерживаются как файлы, так и элементы изображения в ClipboardEvent; совпадающие представления не создают дубли. Текстовые поля и неактивная панель не перехватываются. Подсказка кнопки изображения и справка сочетаний клавиш объясняют способ вставки.
