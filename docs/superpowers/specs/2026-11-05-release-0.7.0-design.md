# Release 0.7.0 — first feature batch

The user requested four changes followed by a local demonstration, with more features to follow. This is development for 0.7.0; publishing is a later step.

## Behavior

- Single SQL runs display their elapsed duration, including the final duration after completion. Use recorded run timestamps so reopening a run remains accurate.
- Date-batch runs display an approximate remaining duration derived from average completed-day execution times. No fabricated estimate before samples exist. Paused, cancelled and completed runs must not show a live countdown; exclude paused time from samples.
- SQL completion matches case-insensitive substrings throughout names, with prefix matches ranked above substring matches. Preserve SQL context, insertion ranges, metadata loading and existing completion limits.
- Markdown supports inline `$...$` and display `$$...$$` LaTeX in the live editor and rendered Markdown. Keep active source editable, leave code spans/fences untouched, and handle malformed formulas without crashing.
- Board notes look like sticky notes. Short text is large and centered horizontally and vertically; font size adapts to text and card dimensions during typing/resizing. Keep long notes readable and accessible, preserve plain text and existing board persistence.

## Approach and constraints

Extend the existing React/Monaco/CodeMirror components rather than replacing editors. Use a maintained math renderer with local bundled assets and trust disabled. Use measured note text fitting rather than character-count heuristics. These implementation choices are the agent's defaults based on the existing application.

An alternate separate math preview would diverge from the existing live Markdown editor; fixed note font sizes would not satisfy dynamic fitting. No schema migration should be needed for the presentation changes. Any timing API additions must be backward compatible.

Preserve existing user data. Create separate demo artifacts. Do not publish/tag the release during this first feature batch.
