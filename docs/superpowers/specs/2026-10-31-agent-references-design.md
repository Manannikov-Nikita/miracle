# Файлы и выбранные блоки в сообщениях агенту

Пользователь запросил ссылки на файлы через `@` и обращение к конкретному выделенному чарту. Реализация расширяет существующий чат и контекст хода, сохраняя минимальный интерфейс для ПК.

## Поведение

- `@` в поле сообщения открывает поиск файлов текущего проекта. Выбор мышью, стрелками и Enter/Tab добавляет компактную удаляемую метку внутри composer и убирает поисковую строку `@…`. Escape закрывает только подсказки. Имена с пробелами и Unicode поддерживаются.
- Выделенные блоки доски показываются рядом с файлами с названиями. Пользователь может убрать блок из следующего сообщения, не снимая выделение на доске. Смена выделения обновляет контекст; отправленный ход сохраняет прежние ID.
- Ссылки сохраняются вместе с сообщением и видны в истории. Текст остаётся обычным текстом; содержимое файлов не копируется автоматически, агент читает указанные пути собственными файловыми инструментами.
- Файлы ограничены корнем текущего проекта; служебное хранилище приложения и выход за корень не допускаются. API возвращает только относительные пути. Выбранные блоки проверяются на принадлежность конкретной доске; сервер берёт их актуальные названия.

## Подход

Выбран разработчиком: структурированные ссылки и метки вместо разбора путей внутри свободного текста. Такой вариант не ломается на пробелах и позволяет явно убрать контекст. Отдельный файловый проводник и прикрепление содержимого файлов не нужны для этого запроса.

Контракт: `AgentTargetContext.filePaths?: string[]`, `boardNodes?: {id: string; title: string}[]`. До 20 файлов и 50 блоков; поиск возвращает до 40 путей и признак усечения. Контекст фиксируется до асинхронного сохранения редактора/доски и повторно используется при повторе одной отправки.

## Проверки

Поиск, клавиатура/IME, пустое состояние и ошибка, отмена устаревшего поиска, разные черновики чатов; выделение/снятие/смена доски, удаление метки и фиксация цели при отправке; границы путей и симлинков; сохранённые ссылки в истории. Затем полный набор тестов, typecheck/build и сценарий с настоящим Codex на текущем стенде. Мобильная вёрстка и Claude не тестируются по прежним указаниям пользователя.
