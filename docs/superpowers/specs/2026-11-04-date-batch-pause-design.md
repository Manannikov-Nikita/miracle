# Пауза запуска по датам после исчерпания попыток

Пользователь просит остановить весь цикл, если все попытки для одной даты завершились ошибкой. Продолжение возможно только после его подтверждения и начинается с той же даты.

## Решение

Добавить сохраняемое состояние `paused` у QueryRun. В нём остаются исходный SQL и диапазон, ошибка текущей даты, прогресс и уже записанные результаты. Кнопка «Продолжить» вызывает `POST /api/query-runs/:id/resume` и повторяет текущую дату с новым набором попыток. Это решение исполнителя в рамках запроса: запуск не создаётся заново и уже успешные даты не повторяются.

Пауза не занимает слот выполнения и переживает перезагрузку страницы и сервиса. Продолжение снова проверяет доступность подключения и свободного слота. Нельзя запустить два продолжения одновременно. «Остановить» завершает серию окончательно; частичные результаты остаются доступны.

В paused-прогрессе `completed=succeeded`, `failed=1`; ошибочная дата ещё не завершена успешно, последующие даты остаются `pending`. При продолжении незавершённая ошибка сбрасывается, счётчики не дублируются. Время ожидания пользователя не входит во время выполнения.

## Рассмотренные варианты

- Ожидание пользовательского ответа внутри работающего цикла проще локально, но держит слот и теряется при рестарте.
- Новый запуск оставшихся дат меняет идентификатор и усложняет объединение результатов без дублей.
- Сохраняемая пауза в том же запуске сохраняет понятный прогресс и позволяет восстановиться после перезагрузки. Выбран этот вариант.

## Границы

Обычные SQL-запросы не меняются. Ошибки структуры результата и хранилища остаются окончательными, поскольку повтор с тем же SQL не исправит совместимость накопленного результата. Пока серия paused, её изменяемый результат нельзя закреплять как финальный снимок на доске или удалять по сроку хранения. Продолжение использует сохранённый источник, а не текущий текст редактора.

## Проверка

Ошибка второй даты после успешной первой: третья дата не выполняется; после подтверждения вторая повторяется, первая не повторяется, итоговый набор не содержит дублей. Проверить повторную паузу, последний день, отмену из паузы, два одновременных продолжения, лимит слотов, восстановление страницы/сервиса, срок хранения и запуск диапазона с доски.
