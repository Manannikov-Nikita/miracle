# Miracle 0.11.0 — изображения, файлы и Markdown

- **Изображения на досках и слайдах.** Загрузка файла, перетаскивание и вставка из буфера через ⌘V / Ctrl+V после щелчка по доске или слайду; PNG, JPEG, GIF и WebP. Изображения сохраняются вместе с проектом и его резервной копией.
- **Метаданные Markdown.** Начальный YAML-блок между `---` остаётся видимым исходным текстом. Имена навыков и описания больше не превращаются в заголовки, ссылки или формулы.
- **Папки и файлы.** Создание папки в дереве проекта; перенос файла в папку или на свободное место дерева для перемещения в корень. Щелчок по свободному месту или Escape снимает выбор: новые файлы и папки создаются в корне. Открытые черновики сохраняются, существующие файлы не перезаписываются.
- **Перенос блоков между панелями.** Лёгкий полупрозрачный эскиз отображается поверх границ доски и презентации.
- **Сертификаты.** HTTPS-подключения Trino и ClickHouse по умолчанию используют доверенные CA Node.js и операционной системы. Ручной PEM заменяет автоматическое доверие только для выбранного подключения; его удаление возвращает автоматический режим. Проверка сертификата и имени сервера остаётся включённой.
- **Таблицы в Markdown.** Кнопка Markdown копирует всю сохранённую таблицу, включая строки за пределами текущей страницы. На доске учитываются видимые столбцы, их названия, форматирование, фильтры и сортировка. Спецсимволы экранируются, переносы строк сохраняются через `<br>`.
- **Favicon.** Вкладка браузера использует логотип Miracle.

SQLite автоматически обновляется со схемы 7 до 8 для хранения изображений. Данные сохраняются, старые доски не требуют изменений. Перед обновлением сохраните резервные копии остановленных проектов командой `miracle backup DIRECTORY`.

Результаты сборки, установки и проверок записаны в [отчёте](release-validation.md).

## Установка и обновление

После публикации v0.11.0 установщик последнего стабильного выпуска будет доступен командой:

```sh
curl -fsSL https://github.com/Manannikov-Nikita/miracle/releases/latest/download/install.sh | sh
```

Для существующей установки:

```sh
miracle update --check
miracle update --to 0.11.0
```

Поддерживаются macOS Apple Silicon (ARM64), GNU/Linux ARM64/x64 и Windows через WSL 2. Установщик проверяет SHA-256 и устанавливает комплект с собственным Node.js. После обновления откройте нужные проекты командой `miracle open`. Каталоги установки, offline-установка и восстановление описаны в [руководстве](local-installation.md).
