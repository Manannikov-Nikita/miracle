# Motion Design Preview

[GIF](assets/miracle-preview.gif) · [Скачать MP4](assets/miracle-preview.mp4?raw=true)

14-секундный обзор Miracle: подключение, SQL-редактор, интерактивная доска и кастомные графики. В ролике снят настоящий интерфейс официального выпуска [0.5.0](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.5.0). Данные синтетические; отдельный демонстрационный проект не содержит рабочих подключений или пользовательских данных.

| Время | Сцена |
| --- | --- |
| 0–0,9 с | Общий вид доски |
| 0,9–3,4 с | Настройки ClickHouse и успешная проверка подключения |
| 3,4–6,3 с | SQL-запрос и его результат: 14 строк |
| 6,3–9,5 с | Перемещение блока с выводами и связанной стрелкой |
| 9,5–12,8 с | Кастомная диаграмма: выделение команд выше средних значений |
| 12,8–14 с | Возвращение к исходной доске |

Переходы и курсор добавлены при монтаже. Запуск запроса, перемещение блока и переключение графика выполнены в приложении. SQL действительно выполнялся в локальном ClickHouse. Trino упомянут как поддерживаемый источник; его подключение в ролике не демонстрируется.

## Подход к анимации

Перед созданием изучены [Remotion Agent Skills](https://www.remotion.dev/docs/ai/skills), [покадровая анимация Remotion](https://www.remotion.dev/docs/animating-properties), [кривые Motion](https://motion.dev/docs/easing-functions) и [stagger](https://motion.dev/docs/stagger). Для этого короткого ролика использован HTML-композитор, Playwright и FFmpeg; Remotion не установлен и не добавлен в зависимости приложения.

Кадр вычисляется из времени, поэтому результат не зависит от скорости браузера. Переходы занимают 480 мс с кривой `cubic-bezier(0.22, 1, 0.36, 1)`. После них есть неподвижные интервалы для чтения. В каждом эпизоде одно действие. Первый и последний кадры совпадают, чтобы цикл повторялся без скачка. Это выбранные параметры данного ролика, а не универсальные нормативы.

## Экспорт и проверка

- GIF: 1200 × 750, 20 кадров/с, 280 кадров, ровно 14 секунд, бесконечный цикл.
- Общая палитра на весь ролик; экспорт без dithering сохраняет ровный фон и чёткие линии интерфейса. См. [FFmpeg palettegen / paletteuse](https://ffmpeg.org/ffmpeg-filters.html#palettegen).
- MP4: H.264, YUV 4:2:0, fast start; содержит тот же монтаж. Скачанный файл можно открыть в видеоплеере и поставить на паузу.
- Проверены загрузка всех исходных кадров, отсутствие ошибок браузера, длительность, число кадров и совпадение начала с концом. Просмотрены контрольные кадры каждой сцены.
