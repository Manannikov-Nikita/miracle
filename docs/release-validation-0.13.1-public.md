# Проверка Miracle 0.13.1

[Стабильный выпуск 0.13.1](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.13.1) опубликован 13 ноября 2026 года в 12:48:00 МСК (09:48:00 UTC). [PR #19](https://github.com/Manannikov-Nikita/miracle/pull/19) влит в `main`; тег `v0.13.1` указывает на коммит `c3653dd4c7bdcbe69f7e9537c091720f6ddfcaf9`. Предыдущий стабильный выпуск — 0.13.0. [Его публичный отчёт сохранён без изменений](release-validation-0.13.0-public.md). [Состав патча](release-0.13.1.md).

## Изменение

Исправлена двойная рамка при выделении блоков на доске и в редакторе презентаций, восстановлены области захвата граней и углов для изменения размера. Исправление одной строки импорта восстанавливает порядок подключения стилей React Flow и оформления Miracle. [Возможности 0.13.0](release-0.13.0.md) сохраняются.

Схема SQLite остаётся 8; переход с 0.13.0 не требует миграции. Проекты схемы 9 из 0.12.0-beta.1 по-прежнему несовместимы со стабильной веткой. Для неё нужна отдельная установка и копия проекта до запуска беты.

## Проверки до публикации

- Локальный прогон на macOS ARM64 с Node 24.22.2: **214 файлов / 2838 тестов, все прошли**. TypeScript клиента и сервера, production build и проверка лицензий прошли; список лицензий не изменился. Сохранились предупреждения jsdom об отсутствии canvas и Vite о размере bundle.
- Desktop-проверка охватила таблицу, заметку, текст, Markdown и фигуру на масштабах 0,475 и 1,597. Области захвата грани и углового маркера составляют 12 и 16 экранных пикселей. Перетаскивание из точки на 6 пикселей снаружи грани меняет высоту примерно на 40 единиц, сохраняя противоположную грань; отмена точно восстанавливает исходную геометрию.
- Нативный архив macOS ARM64 прошёл чистую установку, lifecycle нескольких проектов, backup/restore, Trino HTTPS с тестовым CA, проверку приватности файлов и запуск без системного Node. Формулы, локальная правка ячейки и итоги выполняются нативным DuckDB.
- Обновление публичной 0.13.0 на локальный кандидат 0.13.1 прошло для проектного и явно заданного хранения: схема 8 → 8, сохранность данных и ключей, запросов, досок, результатов, черновиков, профилей, настроек и истории чатов. Ошибки скачивания/checksum и повторное обновление не меняют данные и PID; восстановление старых и новых копий работает. Настоящий сетевой переход после публикации проверен отдельно ниже.

## Публичная установка и обновление

13 ноября 2026 года в 12:49:39 МСК (09:49:39 UTC) завершена проверка на macOS ARM64 с настоящими загрузками из GitHub Release в изолированные каталоги:

- Чистая установка через публичный `latest/download/install.sh` установила 0.13.1 с Node 24.22.2. Профили оболочки не изменились; запуск и повторный запуск прошли, рабочая область и доска сохранились после перезапуска. Схема SQLite — 8.
- Публичная 0.13.0 обнаружила 0.13.1 через `miracle update --check`, сохранив PID работающего проекта. Настоящий сетевой `miracle update` сохранил рабочую область, доску, ключ шифрования, порт и схему 8. Повторные `update --check` и `update` не меняли данные и PID.
- В чистой и обновлённой установках нативный DuckDB выполнил формулы, локальную правку ячейки и итог: суммы 5000 и 36000, общий итог 41000.

## Границы подтверждения

Windows/WSL, мобильный интерфейс, платные запросы Codex/Claude и реальные корпоративные подключения ClickHouse/Trino в этом цикле не проверялись. Linux CI не подтверждает сеть WSL или открытие адреса в браузере Windows. Результаты 0.13.0 не подменяют проверки этого патча.
