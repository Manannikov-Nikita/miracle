# Проверка Miracle 0.12.0

Кандидат подготовлен 10 ноября 2026 года в ветке `codex/release-0.12.0`, от базы 0.11.0 `7ff386a3a1ca8caf1d873ee402b1bdd1938ef5a0`. Реализация находится в отдельном worktree; незавершённые промоматериалы исходного checkout сохранены. Публикация, push и merge не выполнялись.

## Автоматические проверки

- Node **24.22.2**, полный `npm test -- --reporter=dot`: **202 файла, 2 570 тестов — все прошли**. После окончательного уточнения названий действий дополнительно прошли 7 профильных UI-тестов.
- `npm run build`: клиентские и серверные проверки TypeScript, Vite и серверная сборка с нативными ресурсами прошли. Сохраняются предупреждения Vite о размере bundle и аннотациях зависимости; в тестах есть предупреждения React `act`, без проваленных проверок.
- Нативный набор проверяет CSV/TSV, JSON/JSONL, Parquet, XLSX с выбором листа, пустую схему, точные bigint/decimal, даты, JSON и повторяющиеся имена столбцов. Проверены 60 123 входные строки в отдельных чанках при лимите результата в одну строку, отмена и тайм-аут с последующим успешным запросом, запрещённые пути/симлинки/сетевые источники/операции записи, бюджет временных файлов.
- Проверены миграция SQLite 8 → 9, повторяемые операции, регистрация и доска в одной транзакции, обновление нескольких досок, старые черновики и undo, сохранность оформления при несовместимой схеме, переименование/удаление, удержание результатов и закрепление версий выполняющимся запросом.
- HTTP и MCP проверены на реальном локальном движке. Пакетный внешний запрос сохраняет прежний датасет при паузе и переключает его только после успешного продолжения. Сервер восстанавливает связь с активным обновлением и предотвращает повторный запуск того же датасета.
- Генерация notices для 319 пакетов и `git diff --check` прошли. Независимые ревью модели данных и всей реализации завершены без оставшихся замечаний.

Локальные логи сохранены в `.local/release-0.12.0/`: `tests.log`, `build.log`, `review.md`, `datasets-review.md`, `native-report.md`.

## Desktop UI

На отдельном временном проекте через Playwright проверены встроенный источник, выполнение SQL, именование таблицы на доске, запрос по имени датасета и JOIN с CSV, сохранение производного датасета. После перезапуска приложения оба датасета и данные доски доступны.

Изменение исходного SQL через «Обновить датасет по этому SQL» обновило связанную таблицу; производный датасет сохранил прежний снимок. Длительное обновление восстановило статус и кнопку отмены после перезагрузки страницы; отмена сохранила предыдущие данные. Снимок desktop-интерфейса: `.local/release-0.12.0/desktop.png`. Мобильные размеры не проверялись.

## Установленные архивы

Все три финальных архива прошли проверку SHA-256, чистую установку и расширенный `tests/local-install-smoke.mjs` с собственным Node. Проверены XLSX с именованным листом, внешний Trino-запрос к локальному HTTPS fixture → именованная таблица на доске → JOIN с проектным CSV → второй датасет → reinstall → backup/restore → SQL по восстановленным датасетам. Проверены также изоляция проектов, lifecycle и сохранность CA.

В Linux использован Docker `--network none`; Linux x64 выполнялся под эмуляцией на ARM64-хосте. На macOS применён `sandbox-exec` с запретом сети, кроме loopback для локальных fixtures. Контрольный запрос к внешнему адресу получил `EPERM`, loopback работал. XLSX на всех платформах прочитан без доступа к внешней сети.

На macOS также прошёл `tests/upgrade-smoke.mjs` для опубликованной 0.10.0 → кандидата 0.12.0 в двух режимах хранения (project/custom). Проверены миграция 7 → 9, старые и новые backup/restore, сохранность запросов, досок, результатов, редакторов, чатов и настроек, отклонение неверной checksum и сбоя скачивания, отсутствие изменений при повторном обновлении. ## Границы подтверждения

Реальные корпоративные ClickHouse/Trino, отдельный Windows/WSL-хост и реальный Claude CLI не проверялись. Сетевые коннекторы покрыты локальными fixtures; внешний CI не запускался. Ограничения первой версии, включая специальные значения `VARIANT`, описаны в [руководстве](release-0.12.0.md).
