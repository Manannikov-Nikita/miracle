# Miracle 0.12.0 — контекст и действия агента

- **Thinking Orb.** В круглой кнопке свёрнутого чата во время работы агента появилась новая анимация. Она учитывает настройку уменьшения движения.
- **Состав контекста.** Цветная полоса над полем ввода раскрывается вверх и показывает использованные токены, размер окна, доступный остаток и категории: переписка, данные проекта, инструменты, инструкции и остальной контекст. Общий объём берётся из данных Codex или Claude, оценочные категории отмечены «≈». Последний замер сохраняется с чатом; при смене модели или сессии устаревшие значения сбрасываются.
- **Лента действий прямо в чате.** Чтение и поиск файлов, изменения, команды, веб-поиск, планы, инструменты Miracle и работа помощников показываются отдельными шагами с иконками, статусами, краткими результатами и связанными источниками. Во время работы лента раскрыта, после завершения сворачивается в строку с количеством действий. Историю и подробности каждого шага можно открыть снова.
- **Результаты инструментов.** Claude передаёт завершение и ошибки вызовов, инструменты Miracle — фактические краткие итоги. Запуск SQL отмечается как запуск; ход выполнения запроса продолжает отображаться в панели SQL. Просмотр истории и свёрнутой ленты сохраняет положение прокрутки.

Если установленная версия CLI не передаёт данные контекста или размер окна, интерфейс показывает их как недоступные. Новые данные хранятся в существующих сообщениях; схема SQLite остаётся версией 8, миграция после 0.11.1 не требуется.

## Совместимость с бетой

Этот стабильный выпуск продолжает ветку 0.11.1 и не включает DuckDB и датасеты из 0.12.0-beta.1. Проекты, уже открытые в той бете, имеют схему 9 и не откроются в стабильной 0.12.0 со схемой 8. Не обновляйте используемую для них beta-установку этим выпуском: обычный `miracle update` считает стабильную 0.12.0 более новой, а установщик запрещает обратное понижение. Для стабильной ветки используйте отдельную установку и копию проекта, сделанную до запуска беты.

## Установка и обновление

Установщик последнего стабильного выпуска:

```sh
curl -fsSL https://github.com/Manannikov-Nikita/miracle/releases/latest/download/install.sh | sh
```

Для существующей установки:

```sh
miracle update --check
miracle update --to 0.12.0
```

Поддерживаются macOS Apple Silicon (ARM64), GNU/Linux ARM64/x64 и Windows через WSL 2. Установщик проверяет SHA-256 и устанавливает комплект с собственным Node.js. После обновления откройте нужные проекты командой `miracle open`.
