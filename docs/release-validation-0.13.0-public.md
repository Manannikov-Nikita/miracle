# Проверка Miracle 0.13.0

[Стабильный выпуск 0.13.0](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.13.0) опубликован 13 ноября 2026 года в 11:41:45 МСК (08:41:45 UTC). [PR #17](https://github.com/Manannikov-Nikita/miracle/pull/17) влит в `main`; тег `v0.13.0` указывает на коммит `c27a5d61a41f07a117f823ded81f6759f97dee69`. Выпуск подготовлен на основе стабильной 0.12.0. [Её публичный отчёт сохранён отдельно](release-validation-0.12.0-public.md). [Состав выпуска и совместимость](release-0.13.0.md).

## Изменения и границы

Редактируемые таблицы с формулами на DuckDB: ручные таблицы и режим «ƒ Формулы» для сохранённых SQL-снимков, локальные правки ячеек, фильтры, сортировка и итоги. AG Grid Community отвечает за отображение и ввод. Добавлены действия с файлами в проводнике, точные границы фигур и линий, направляющие равных промежутков, плавающие панели и перетаскивание инструментов на холст.

Схема SQLite остаётся 8; переход с 0.12.0 не требует новой миграции. DuckDB используется для вычислений в табличном режиме. Датасеты, SQL-запросы к файлам проекта и схема 9 из 0.12.0-beta.1 не включены. Проекты схемы 9 нельзя открывать этим выпуском; автоматического обратного преобразования нет. Установщик считает 0.13.0 новее этой беты и запрещает обратное понижение, поэтому для стабильной ветки нужна отдельная установка и копия проекта до запуска беты.

Формулы таблицы пока не переносятся в графики; в презентации таблица доступна без редактирования. Для кастомного графика предпросмотр перетаскивания показывает название, не запуская второй экземпляр iframe. Полные границы табличного режима перечислены в [заметках выпуска](release-0.13.0.md#таблицы-границы-первой-версии).

## Локальные проверки до публикации

- Полный прогон на macOS ARM64 с закреплённым Node 24.22.2: **214 файлов / 2838 тестов, все прошли**. Предупреждения jsdom об отсутствии canvas не влияют на результат.
- TypeScript клиента и сервера, production build и генерация лицензий прошли. Сохраняется предупреждение Vite о размере bundle.
- Независимое ревью охватило табличные вычисления, работу с файлами и черновиками, геометрию линий, направляющие и перетаскивание. Найденные ошибки точности вычислений, переходов фокуса, предела SQL-черновика и возврата конца линии исправлены и проверены регрессионными тестами.
- Desktop-проверка таблицы подтвердила сохранение фокуса при переходе от имени столбца к формуле, сохранение последней правки при немедленном закрытии расширенного редактора и восстановление данных после перезагрузки.
- Собран нативный архив macOS ARM64 0.13.0 с Node 24.22.2. Чистая установка, lifecycle нескольких проектов, backup/restore, Trino HTTPS с тестовым CA, приватность файлов и запуск без системного Node прошли.
- Табличный API из установленного архива выполнил формулы и локальную правку ячейки через нативный DuckDB: суммы 5000 и 36000, общий итог 41000.

Нативный переход с публичной 0.12.0 на кандидат 0.13.0 через CLI прошёл для проектного и явно заданного хранения: схема 8 → 8, сохранность данных, ключей, запросов, досок, результатов, черновиков, профилей, настроек и истории чатов. Ошибки скачивания/checksum и повторное обновление не меняют данные и PID; восстановление старых и новых копий работает. В этой проверке транспорт обновления подставлял локальные файлы кандидата в официальный путь; фактический сетевой переход после публикации проверен отдельно ниже.

## CI и публикация

- [Проверки PR перед слиянием](https://github.com/Manannikov-Nikita/miracle/actions/runs/43392844373) завершились успешно на macOS ARM64, Linux ARM64 и Linux x64 для финального коммита ветки `8e67b6477b288d319c723b9032393be7ff9173a6`.
- [Проверки `main`](https://github.com/Manannikov-Nikita/miracle/actions/runs/43393989029) прошли на тех же трёх платформах для релизного коммита `c27a5d61a41f07a117f823ded81f6759f97dee69`.
- [Release workflow](https://github.com/Manannikov-Nikita/miracle/actions/runs/43394069360) повторил матрицу проверок и опубликовал три архива, их `.sha256` и `install.sh` из этого коммита.

Первый запуск CI обнаружил гонку чтения JSONL-журнала fake Codex CLI: тест мог прочитать ещё не завершённую запись. Исправлено только чтение журнала в тесте; добавлены проверки пустой и незавершённой записи. Последующие проверки трёх платформ прошли.

На каждой платформе прошли тесты, production build, проверка лицензий, сборка архива с закреплённым Node 24.22.2, установка и lifecycle с bundled runtime, табличные вычисления нативного DuckDB, backup/restore и переход с опубликованной 0.12.0 через CLI. Необязательная задача `connectors` с реальными ClickHouse/Trino была пропущена; её запуск не входит в подтверждённый результат CI.

## Публичная установка и обновление

13 ноября 2026 года в 11:43:25 МСК (08:43:25 UTC) завершена проверка на macOS ARM64 с настоящими загрузками из GitHub Release в изолированные каталоги:

- Чистая установка через публичный `latest/download/install.sh` установила 0.13.0 с Node 24.22.2. Профили оболочки не изменились; запуск и повторный запуск прошли, рабочая область и доска сохранились после перезапуска. SQLite остался на схеме 8.
- Публичный установщик 0.12.0 установил предыдущую версию. Её `miracle update --check` нашёл 0.13.0, сохранив PID работающего проекта.
- Настоящий сетевой `miracle update` обновил 0.12.0 до 0.13.0. Сохранились рабочая область, доска, ключ шифрования, порт и схема 8. Повторные `update --check` и `update` на актуальной версии не меняли данные и PID.
- В чистой и обновлённой установках табличный API выполнил вычисления через нативный DuckDB: локальная правка количества до 20 дала суммы 5000 и 36000, общий итог 41000.
- Пользовательская установка не изменялась. После проверки оба тестовых проекта остановлены, временные установки и данные удалены; очистка подтверждена.

## Границы подтверждения

Реальные платные запросы Codex/Claude, Windows/WSL, мобильный интерфейс и внешние корпоративные ClickHouse/Trino в этом цикле не проверялись. Адаптеры Codex/Claude и сетевые состояния проверены автоматическими тестами с контролируемыми провайдерами; это не заменяет проверку живого сервиса. Linux CI не подтверждает сеть WSL или открытие адреса в браузере Windows.
