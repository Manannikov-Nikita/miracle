# Проверка Miracle 0.11.0

[Miracle 0.11.0](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.11.0) опубликована 10 ноября 2026 года в 08:57 МСК (05:57 UTC). Тег `v0.11.0` указывает на merge-коммит `55ac297233987e450f934c5cca6fa2715951d473`; дерево совпадает с проверенным PR-коммитом `73cc42aed0c24c87dcc3c215a3f0ef3c24afbb2b`. [Отчёт предыдущего выпуска сохранён отдельно](release-validation-0.10.0-public.md).

## Изменения

Изображения на досках и слайдах, включая вставку через ⌘V / Ctrl+V; корректные YAML-метаданные Markdown; создание папок и перенос файлов с сохранением черновиков; эскиз переноса блоков поверх панелей; автоматические доверенные CA системы и Node с ручным PEM; копирование всей таблицы в Markdown; favicon. Корень проекта выбирается щелчком по свободному месту дерева или Escape, туда же можно перенести файл. SQLite переходит со схемы 7 на 8 для хранения изображений. [Подробности выпуска](release-0.11.0.md).

## Проверки кандидата

- Логи находятся в `.local/release-0.11.0`.
- Полный локальный прогон Node 24.22.2: **195 файлов / 2500 тестов, все прошли** (`tests-publication.log`). TypeScript, production build и notices прошли; 316 пакетов, notices без изменений. Сохраняется предупреждение Vite о размере bundle.
- Нативная сборка macOS ARM64 прошла чистую установку, lifecycle, backup/restore и запуск без системного Node. Обновление опубликованной 0.10.0 до кандидата проверено для project/custom storage: схема 7 → 8, сохранность данных, старые/новые резервные копии, неверная checksum и сбой скачивания, отсутствие изменений при повторном обновлении (`install.log`, `upgrade.log`).
- Независимые ревью не оставили существенных замечаний. Проверены хранение и ссылки изображений, ограничения путей и симлинков, коллизии и блокировки при переносе файлов, черновики и запоздавшие ответы, метаданные с BOM/CRLF, clipboard и отмена переноса. TLS проверен локальными HTTPS-серверами: автоматические CA, изолированный ручной PEM, недоверенный издатель и неверное имя сервера.
- Desktop UI проверен через **@Browser** на отдельном временном проекте: Markdown-метаданные и основной текст, создание папок, перенос несохранённого SQL между папками и в корень, загрузка/вставка изображения на доску и слайд, полноэкранная презентация, копирование таблицы в Markdown и настройки CA. Вставленные изображения сохраняются после перезагрузки; неактивная панель и текстовые поля не перехватывают вставку.

## Границы подтверждения

Реальные корпоративные ClickHouse/Trino, отдельный Windows/WSL-хост и реальный Claude CLI заново не проверялись. TLS покрыт синтетическими сертификатами и локальными HTTPS-серверами; мобильные устройства не тестировались. Отдельный аудит безопасности не выполнялся.

Копирование таблиц использует существующие ограничения API снимков: 50 000 строк, 20 MiB, 1 000 000 ячеек; при превышении возвращается ошибка, а не усечённая таблица. Перенос файлов между разными файловыми системами отклоняется без изменения исходного файла.
