# Проверка Miracle 0.11.1

[Miracle 0.11.1](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.11.1) опубликована 10 ноября 2026 года в 12:12 МСК (09:12 UTC). Тег `v0.11.1` указывает на merge-коммит `74d1077f87f0390c113f5aa5986f3e5ec3437a95`; его дерево совпадает с проверенным PR-коммитом `38132632c5aea0153e653e7ed6d7d538c7e0ba77`. База — стабильная 0.11.0 (`7ff386a`). [Отчёт опубликованной 0.11.0 сохранён отдельно](release-validation-0.11.0-public.md).

## Изменения и границы

В 0.11.1 перенесена только поддержка beta-канала в CLI и установщике. Обычный `miracle update` выбирает стабильные выпуски; `miracle update --beta` явно разрешает тестовый выпуск для одной команды. После обновления с 0.11.0 пользователи могут перейти на уже опубликованную 0.12.0-beta.1 без ручной переустановки.

База остаётся на схеме 8, зависимости и код интерфейса не изменены. DuckDB, датасеты и схема 9 остаются в отдельной бете. Для её запуска с существующим проектом нужна предварительная резервная копия; понижение версии установщиком запрещено.

## Проверки кандидата

- TypeScript, production build и notices прошли на Node 24.22.2; 316 пакетов, notices без изменений. Сохраняется предупреждение Vite о размере bundle.
- Полный локальный прогон Node 24.22.2: **196 файлов / 2530 тестов, все прошли**. Первый запуск внутри ограниченной песочницы остановлен; подтверждённый прогон выполнен с доступом к локальным тестовым серверам.
- Независимое ревью не выявило существенных замечаний: проверены состав backport, согласие на beta, сравнение версий, отказ от понижения, проверка launcher и стабильный pipeline публикации. Отдельный прогон тестов установщика и updater: 44/44 прошли.
- Собраны три архива macOS ARM64, Linux ARM64/x64; контрольные суммы проверены, DuckDB в payload отсутствует. На macOS ARM64 прошло обновление опубликованной 0.11.0 через настоящий CLI в project/custom storage: схема 8 → 8, сохранность данных и ключей, отказ при сбое скачивания/checksum, неизменный PID при проверке актуальной версии, восстановление старых и новых копий.
- Все три архива прошли установку, lifecycle и backup/restore без сети: macOS ARM64 нативно, Linux ARM64/x64 в Docker (x64 через эмуляцию). Нативные Linux runners также прошли CI. Логи кандидата и публичных проверок собраны в `.local/release-0.11.1`.
- [PR #13](https://github.com/Manannikov-Nikita/miracle/pull/13), [проверки PR](https://github.com/Manannikov-Nikita/miracle/actions/runs/42786565391), [проверки main](https://github.com/Manannikov-Nikita/miracle/actions/runs/42787614441) и [публикация по тегу](https://github.com/Manannikov-Nikita/miracle/actions/runs/42787649688) завершены успешно. На всех трёх нативных runners прошли тесты, build, упаковка, чистая установка и обновление с 0.11.0. Необязательный job внешних коннекторов не запускался.

## Публикация

Все семь assets скачаны анонимно: размеры и SHA-256 совпали с GitHub, архивы — также с опубликованными `.sha256`. Установщик `latest/download/install.sh` побайтно совпадает с установщиком `v0.11.1`. Стабильный latest — 0.11.1; 0.12.0-beta.1 остаётся отдельным prerelease. Подробности: `.local/release-0.11.1/public-verification.json`.

Чистая онлайн-установка публичным `latest/download/install.sh` на macOS ARM64 прошла без `MIRACLE_ARCHIVE` и системного Node. Проверены bundled Node 24.22.2, версия 0.11.1, start/status/stop, схема 8, создание доски через API и её сохранность после перезапуска. Shell profiles не менялись; временная установка и проект удалены. Лог: `.local/release-0.11.1/public-clean-install.log`.

Настоящий сетевой переход на macOS ARM64 прошёл без подмены транспорта или архива: установленная публичная 0.11.0 нашла и установила 0.11.1 обычным `miracle update`. Схема осталась 8, workspace и доска сохранились. Повторные обычные `update --check` и `update` не меняли работающий процесс и не выбирали существующую бету.

Затем `miracle update --beta --check` предложил 0.12.0-beta.1, а `miracle update --beta` установил её в те же каталоги. Проверены сохранность workspace/доски, схема 9 и успешный запрос к CSV через DuckDB. Попытка обычного обновления с беты на более раннюю стабильную 0.11.1 отклонена без изменения процесса и данных. Временная установка удалена после подтверждённой остановки. Лог: `.local/release-0.11.1/public-online-smoke.log`.

## Границы подтверждения

Реальные корпоративные ClickHouse/Trino, Windows/WSL и Claude CLI заново не проверялись: этот patch не меняет соответствующие runtime-пути. Изменений интерфейса нет; отдельная desktop-проверка не выполнялась.
