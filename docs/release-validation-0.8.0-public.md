## Публичная установка и обновление

На macOS ARM64 в отдельных временных установках прошли:

- Чистая и повторная установка через публичный `install.sh` без локального архива в положительных сценариях и без системного Node в PATH. Проверены lifecycle, несколько проектов, backup/restore, приватные файлы состояния и сохранение Trino CA.
- Все четыре онлайн-перехода **архивных выпусков без встроенного обновления × стандартные/нестандартные пути → 0.8.0**. Сохранились ключи, секреты, SQL, доски, результаты и прежний origin; проверены отклонение неверной контрольной суммы и восстановление старой/новой копии.
- Реальный CLI-переход **0.7.0 → 0.8.0** через официальный GitHub Release. `update --check` сохранил работающий процесс; обновление сохранило пути, ключ и рабочую область. Схема SQLite осталась 5; доска, редактор, чат, история и зашифрованный профиль сохранились после запуска. Команда `miracle` работает в новой zsh после настройки PATH.
- `update --check` и `update` на актуальной 0.8.0 сохранили процесс и данные.
- Через API подтверждено сохранение презентации после перезапуска: метаданные слайда, оформление текста, фигура, стрелка и сохранённый SQL-снимок; фильтрация документов по типу осталась корректной. Сохранились также свободная стрелка с оформлением и исходники/данные кастомного графика. Это проверки хранения через API, они не подтверждают браузерную отрисовку опубликованной сборки; у кастомного графика статус рендера остался `not_observed`.

Все три этапа публичной проверки завершились с кодом **0**. CLI-проверка завершена **6 ноября 2026 года, 20:57:49 UTC**, установка и четыре legacy-обновления — **20:59:00 UTC**. ## Границы подтверждения

Сохраняется ранее известное предупреждение **low** для вложенного **KaTeX 0.16.47** в `micromark-extension-math`: [GHSA-238p-pmpm-9mq7](https://github.com/advisories/GHSA-238p-pmpm-9mq7). Прямая зависимость KaTeX — **0.19.1**; наличие новой прямой версии не устраняет предупреждение для вложенной копии. Это прежнее неустранённое предупреждение, а не исправление в 0.8.0. Возможность эксплуатации в Miracle отдельно не исследовалась.

Полная матрица реальных ClickHouse/Trino/TLS-интеграций, реальный Claude CLI, Windows/WSL-хост и мобильный браузер в этом прогоне не проверялись. Нативный Linux CI не подтверждает работу на Windows-хосте с WSL 2 и открытие адреса в браузере Windows.

Экспорт презентаций в PDF/PPTX не входит в выпуск. Для панели Git нужен системный Git или путь `MIRACLE_GIT_BINARY`; само приложение запускается без Git. Локальные тестовые документы, датасеты, скриншоты и базы не входят в поставку. Остальные функциональные ограничения перечислены в [подробном отчёте](release-validation-0.8.0.md).
