# Проверка и публикация Miracle 0.3.0

[Miracle 0.3.0](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.3.0) опубликован **1 ноября 2026, по Москве**. `releases/latest` указывает на этот выпуск; доступны четыре архива, четыре SHA-256 и `install.sh`. При начале разработки основная ветка была сверена с GitHub: `origin/main` — `8be0d5e`. Основные изменения вмержены через [PR #3](https://github.com/Manannikov-Nikita/miracle/pull/3).

## Локальная проверка

Проверено на macOS arm64 с Node.js 24.22.2:

- `npm test`: **819 тестов в 74 файлах**, все прошли.
- `npm run build`, включая оба TypeScript-проекта: прошёл. Сохраняется предупреждение Vite о размере основного клиентского чанка.
- `npm run notices`: лицензии обновлены; `npm audit --omit=dev`: **0 уязвимостей**. Для `@fastify/static` закреплена исправленная транзитивная цепочка glob 14.0.3 / minimatch 11.0.3.
- SQLite + реальные ClickHouse/Trino: **11 интеграционных групп** прошли, включая точность результатов, метаданные, даты, отмену, перезапуск и backup/restore.
- ClickHouse HTTPS/mTLS: **6 групп** прошли, включая доверие CA, клиентскую аутентификацию, сжатие, точные числа и таймауты.
- Проверены четыре финальных архива из нативного CI: macOS arm64/x64 и GNU/Linux arm64/x64. Проверены закреплённые SHA-256 runtime, итоговые контрольные суммы и содержимое payload; проектные базы, ключи, `.env` и локальные данные не включены.
- Финальный архив macOS arm64 прошёл чистую установку без системного Node.js, запуск нескольких проектов, переустановку работающих экземпляров, явное старое хранилище, Trino CA, права доступа и backup/restore.
- Установленные `miracle update --check` и `miracle update` проверены с настоящим GitHub после публикации: обе команды корректно сообщают, что 0.3.0 актуальна. Версия, PID, порт, ключ, доска и данные работающего проекта не меняются. Переход на более новый выпуск покрыт детерминированными тестами updater; следующего публичного выпуска пока нет.

## Совместимость обновления

`tests/upgrade-smoke.mjs` использует настоящие опубликованные архивы 0.2.0 и 0.2.1 и установщик кандидата. Для каждой версии проверяются глобальный `data/` и пользовательское хранилище, включая пробелы и Unicode в путях.

На финальном macOS arm64 архиве прошли **4 из 4 сценариев**, включая **8 восстановлений** старых и новых резервных копий.

Проверяются отказ при неправильной контрольной сумме без остановки старого сервиса, аутентифицированное завершение старого процесса, сохранение собственного каталога launcher и подсказка старого адреса. После открытия на прежнем порту проверяются ключ и зашифрованные пароль/Trino CA, реальные запросы к тестовому источнику, сохранённые SQL, доски, результаты и переход схем 2/3→4. Старые и новые резервные копии восстанавливаются в пустые проекты; документы и чаты сохраняются, доверие перенесённым профилям сбрасывается.

Регрессии подготовки релиза:

- Установщик повторно проверяет активную версию под блокировкой до остановки проектов. Проверено, что конкурирующее обновление и ручной установщик не понижают уже установленную версию.
- Браузерные черновики импортируются пакетами до 1 MiB UTF-8 / 200 документов. Отдельный большой документ использует ограниченный маршрут импорта до 8 MiB; общий лимит HTTP остаётся 2 MiB. Проверены ASCII, Unicode, более 200 вкладок, потерянный ответ после сохранения, повтор и добавление вкладок между попытками. Старые тексты остаются в браузере до успешного завершения.
- SQL/доска и агент синхронизируют ревизии; независимые переключатели областей сохраняют содержимое и размеры. Интерфейс проверен в настольном браузере.
- Нативный CI выявил аварийное завершение встроенного HTTP-клиента Node 24.22.2 на macOS ARM при `setTypeOfService EINVAL`. Установщик, CLI, updater и Trino используют поставляемый undici с собственным диспетчером и явным освобождением соединений. Четыре регрессии принудительно воспроизводят ошибку в дочерних процессах и проверяют управление сервисом, установку, Trino без CA и закрытие непрочитанного ответа. Причина и исправление зависимости описаны в [upstream PR](https://github.com/nodejs/undici/pull/5547).
- При разборе повторного сбоя CI в тесте чата воспроизведена гонка завершения CLI на macOS: сигнал уже завершающейся группе возвращал `EPERM`. Теперь ошибка допускается только после закрытия CLI и подтверждения отсутствия группы; живой процесс и оставшийся потомок сохраняют ошибку. Отдельно заглушка CLI дожидается записи stdout перед выходом. Проверены три регрессии остановки, сохранение чата при задержанном выводе и 64 повторных сценария без сбоев; таймауты не увеличивались.

## CI и границы проверки

Все четыре платформы прошли тесты, сборку, установку и обновления с обоих старых выпусков в [CI 41244229789](https://github.com/Manannikov-Nikita/miracle/actions/runs/41244229789), коммит `5888348`. Опубликованы все четыре архива именно из этого запуска. Их SHA-256 и одинаковость четырёх копий установщика проверены перед публикацией. Старые архивы и их runtime в проверках не изменялись.

Тег `v0.3.0` сохранён на `bf219ff`. Его workflow останавливался на секундном ожидании загрузки редактора в UI-тестах macOS Intel, включая повторный запуск. В `5888348` изменены только два тестовых ожидания на пять секунд, при общем лимите теста 15 секунд; проверки DOM и настоящий WebCrypto сохранены. Все исходные файлы, из которых собирается релиз, включая код приложения, манифесты зависимостей, сборщик и установщик, побайтно совпадают с тегом. Публикация выполнена из проверенных артефактов CI основной ветки; запуск workflow по тегу не объявляется успешным.

Реальный Codex CLI проверен в этой разработке с файлами проекта, SQL и доской, включая ссылки `@` и выделенный чарт. Реальный Claude CLI и Windows/WSL не проверялись по принятой границе работы; детерминированные тесты обоих адаптеров входят в общий набор. Мобильная вёрстка не проверялась: приложение рассчитано на ПК.

## Проверка публичного выпуска

После публикации анонимно скачаны все четыре архива и файлы SHA-256; их суммы совпадают с проверенным CI-набором и digest в GitHub API. Установщик `latest/download/install.sh` побайтно совпадает с `v0.3.0/install.sh`.

На macOS arm64 прошли чистая онлайн-установка, переустановка и **4 из 4 онлайн-обновлений**: 0.2.0/0.2.1 × стандартное/пользовательское хранилище. Положительные сценарии запускают публичный установщик без `MIRACLE_ARCHIVE`, поэтому он сам скачивает новый выпуск. Проверены остановка старого экземпляра, отказ при неверной сумме, миграция схемы, прежний адрес, ключ и зашифрованные данные, запросы, доски, результаты, API импорта черновиков и восстановление старых/новых копий. Временные установки удалены после проверок.
