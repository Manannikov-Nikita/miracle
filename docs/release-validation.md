# Проверка Miracle 0.8.1

[Miracle 0.8.1 опубликован](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.8.1) **7 ноября 2026 года, 00:38:22 МСК**. Все три поддерживаемые платформы прошли CI. Анонимное скачивание и реальное онлайн-обновление подтверждены.

Изменения: поддержка macOS Apple Silicon (ARM64), GNU/Linux ARM64/x64; актуальные инструкции установки и встроенного обновления, исключение устаревших выпусков без команды `miracle update` из раздачи и CI. На macOS x64 установщики отказывают до загрузки и изменения установки.

## Локальные проверки

- Node.js **24.22.2**: **158 файлов / 2 039 тестов** прошли. Журнал: `.local/release-0.8.1/tests-final.log`.
- `npm run build`: обе проверки TypeScript и production-сборка прошли. Сохраняется предупреждение Vite о размере клиентского bundle. Журнал: `.local/release-0.8.1/build.log`.
- `npm run notices`: **316 пакетов**, `THIRD_PARTY_NOTICES.md` без изменений. `git diff --check` прошёл.
- Нативный архив macOS ARM64 собран с проверкой SHA-256 Node runtime. Чистая и повторная установка без системного Node, несколько проектов, lifecycle, Trino HTTPS CA, private state и backup/restore прошли. Журналы: `.local/release-0.8.1/archive.log`, `.local/release-0.8.1/install.log`.
- Регрессии проверяют отказ macOS x64 в сборщике, shell bootstrap и прямом установщике, а также публикацию только трёх обязательных пар архив/контрольная сумма.

- Обновление опубликованной **0.8.0 → кандидат 0.8.1** через реальный CLI прошло для обычного и нестандартного хранилища, включая Trino TLS fixture. Проверены check-only, ошибки загрузки и checksum, остановка своего процесса при активации, сохранение ключей/секретов/SQL/доски/результата/редактора и старого origin, восстановление старой и новой копии, no-op актуальной версии. До публикации официальные сетевые ответы заменялись локальными артефактами только в тестовом процессе.
- Независимое ревью не нашло блокирующих замечаний. Проверка через настоящие публичные GitHub URL описана ниже.

## Публичные загрузки и обновление

Все семь файлов скачаны без авторизации с HTTP 200. Размеры и SHA-256 совпали с metadata GitHub, а архивы — с опубликованными `.sha256`.

Фиксированный и `latest/install.sh` побайтово совпали: **2887 байт**, SHA-256 `db84a498adfc175a930a265c65840f6075dccbfee525e580729b31e38ac19650`. Сводка проверки: `.local/release-0.8.1/public/verification.json`, `passed: true`.

На macOS ARM64 проверен настоящий публичный CLI-переход **0.8.0 → 0.8.1** без подмены сети или локального архива: `--check` сохранил работающий процесс, обновление корректно остановило его и сохранило пути установки, ключ, SQLite, доски, SQL-редактор, чаты/историю и зашифрованный профиль. После запуска сохранены презентация, оформление текста/фигуры/стрелки и SQL-результаты. Это проверки хранения через API, а не визуальная проверка браузера. `miracle update --check` и `miracle update` на актуальной версии сохранили процесс и данные. Команда доступна в новой zsh после настройки PATH. Журнал: `.local/release-0.8.1/public-cli-update.log`, exit 0.

Чистая и повторная онлайн-установка 0.8.1 через публичный `install.sh` тоже прошла без `MIRACLE_ARCHIVE` и без системного Node в PATH: lifecycle, несколько проектов, Trino HTTPS CA, приватное состояние, backup/restore и no-op актуального обновления подтверждены. Журнал: `.local/release-0.8.1/public-install.log`, exit 0.

## Снятие устаревших выпусков с раздачи

Выпуски native-поставки без встроенной команды обновления переведены в черновики GitHub Release с сохранением файлов. Их прежние публичные URL установщика и ARM-архива возвращают HTTP 404 без авторизации. Публичные заметки восьми поддерживаемых предыдущих релизов обновлены: устаревшие инструкции перехода убраны. Git-история и ранее скачанные пользователями файлы не переписывались.

## Границы подтверждения

Локальная проверка macOS ARM64 не заменяет Linux CI. Реальный Windows/WSL-хост, Claude CLI, мобильный браузер и полная матрица внешних ClickHouse/Trino/TLS в этом maintenance-выпуске отдельно не проверяются.

Сохраняются ранее известное предупреждение о размере JS bundle и low advisory вложенного KaTeX, описанные в [проверке предыдущего выпуска](release-validation-0.8.0-public.md). Зависимости в этом выпуске не менялись.

История предыдущего выпуска: [публичная проверка 0.8.0](release-validation-0.8.0-public.md), [функциональная проверка 0.8.0](release-validation-0.8.0.md).
