# Проверка Miracle 0.11.1

Кандидат стабильного выпуска 0.11.1 подготовлен от проверенной базы 0.11.0 (`7ff386a`). [Отчёт опубликованной 0.11.0 сохранён отдельно](release-validation-0.11.0-public.md).

## Изменения и границы

В 0.11.1 перенесена только поддержка beta-канала в CLI и установщике. Обычный `miracle update` выбирает стабильные выпуски; `miracle update --beta` явно разрешает тестовый выпуск для одной команды. После обновления с 0.11.0 пользователи могут перейти на уже опубликованную 0.12.0-beta.1 без ручной переустановки.

База остаётся на схеме 8, зависимости и код интерфейса не изменены. DuckDB, датасеты и схема 9 остаются в отдельной бете. Для её запуска с существующим проектом нужна предварительная резервная копия; понижение версии установщиком запрещено.

## Проверки кандидата

- TypeScript, production build и notices прошли на Node 24.22.2; 316 пакетов, notices без изменений. Сохраняется предупреждение Vite о размере bundle.
- Полный локальный прогон Node 24.22.2: **196 файлов / 2530 тестов, все прошли**. Первый запуск внутри ограниченной песочницы остановлен; подтверждённый прогон выполнен с доступом к локальным тестовым серверам.
- Независимое ревью не выявило существенных замечаний: проверены состав backport, согласие на beta, сравнение версий, отказ от понижения, проверка launcher и стабильный pipeline публикации. Отдельный прогон тестов установщика и updater: 44/44 прошли.
- Собраны три архива macOS ARM64, Linux ARM64/x64; контрольные суммы проверены, DuckDB в payload отсутствует. На macOS ARM64 прошло обновление опубликованной 0.11.0 через настоящий CLI в project/custom storage: схема 8 → 8, сохранность данных и ключей, отказ при сбое скачивания/checksum, неизменный PID при проверке актуальной версии, восстановление старых и новых копий.
- Все три архива прошли установку, lifecycle и backup/restore без сети: macOS ARM64 нативно, Linux ARM64/x64 в Docker (x64 через эмуляцию). Нативные Linux runners будут отдельно подтверждены CI. Логи кандидата: `/private/tmp/miracle0111-native/<target>/`, полный прогон — `/private/tmp/miracle-0111-tests-native.log`.
- CI ещё не запускался; результаты будут добавлены после завершения.

## Публикация

Тег и публичные файлы 0.11.1 пока не созданы. После успешного CI нужно проверить три архива, SHA-256, стабильный latest и настоящий сетевой переход 0.11.0 → 0.11.1 → 0.12.0-beta.1 с сохранением данных.

Реальные корпоративные ClickHouse/Trino, Windows/WSL и Claude CLI заново не проверяются: этот patch не меняет соответствующие runtime-пути. Изменений интерфейса нет; отдельная desktop-проверка не требуется.
