# Проверка Miracle 0.2.1

Проверено 30 октября 2026 на macOS arm64, Node.js 24.22.2. Изменение добавляет CA для Trino HTTPS и миграцию SQLite со схемы 1/2 на 3.

- Полный набор: 635 тестов в 47 файлах, без пропусков.
- TypeScript и сборка клиента/сервера прошли. Остаётся прежнее предупреждение Vite о размере основного клиентского чанка.
- SQLite + реальные ClickHouse/Trino: 11 интеграционных групп прошли, включая интроспекцию, выгрузки по датам, отмену и backup/restore.
- Синтетический HTTPS Trino: отказ без CA, с чужим CA и неправильным именем сервера; успех с нужным CA, POST/GET/DELETE, отмена после ошибки и параллельная отмена, изоляция доверия, отсутствие оставшихся сокетов.
- API: CA шифруется, ответы содержат только флаг наличия; проверены сохранение при пропуске поля, замена/удаление, PEM-валидация, черновая проверка и отсутствие записи при проверке.
- Миграции SQLite 1/2→3 и backup/restore схем 1, 2, 3 прошли, включая откат при ошибке миграции.
- Браузер: понятная ошибка без CA, выбор PEM, успешная проверка, сохранение, повторное открытие с флагом «Сохранён» и успешная проверка сохранённого CA. Ошибок консоли нет.
- Архив `miracle-0.2.1-darwin-arm64.tar.gz`: чистая установка без системного Node.js, Trino HTTPS с CA через API установленного приложения, переустановка, сохранность CA и backup/restore прошли. На опубликованном архиве 0.2.0 этот же сценарий воспроизводил `fetch failed`.
- Независимое ревью не нашло блокеров; `git diff --check` чистый. Production-зависимость undici включена в lockfile, архив и лицензии.

[Выпуск 0.2.1](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.2.1) опубликован из коммита `55537b2f36695da1ab57c43f835d578e973f10e0` в `main`.

- [CI в main](https://github.com/Manannikov-Nikita/miracle/actions/runs/41120035423) и [публикация](https://github.com/Manannikov-Nikita/miracle/actions/runs/41120099295) завершились успешно. Тесты, сборка и проверка установки прошли на macOS/Linux, arm64/x64.
- Анонимно скачаны установщик `latest` и все четыре опубликованных архива; установщик совпадает с исходником версии 0.2.1, SHA-256 каждого архива совпадает с опубликованной контрольной суммой.
- На macOS arm64 пройдена установка через публичный установщик GitHub без системного Node.js. Повторная проверка опубликованного архива подтвердила Trino HTTPS с CA, переустановку, сохранность CA и backup/restore.

Корпоративные серверы, сертификаты и учётные данные пользователей в проверках не использовались. Проверка WSL 2 вместе с браузером Windows на реальном Windows-хосте не выполнялась.

Предыдущие проверки: [0.2.0](release-validation-0.2.0.md), [0.1.0](release-validation-0.1.0.md).
