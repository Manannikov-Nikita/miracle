# Проверка Miracle 0.7.0

Miracle 0.7.0 опубликован. Все четыре платформы прошли CI; анонимное скачивание, контрольные суммы, чистая установка и публичные обновления подтверждены.

Изменения включены в `main` через [PR #7](https://github.com/Manannikov-Nikita/miracle/pull/7) **6 ноября 2026 года, 06:14:48 UTC**. Merge-коммит и тег `v0.7.0` указывают на `4f773b33bf8f1c94f788c8694ae49e2807442db6`.

Состав выпуска, сценарии Browser, замеры перемещения блоков и ограничения: [подробная проверка 0.7.0](release-validation-0.7.0.md). Основные изменения — общие преобразования таблиц и графиков, melt/pivot без агрегации, LaTeX, стикеры и улучшения поиска, чата и управления доской.

## Локальные проверки

На Node.js **24.22.2** прошли **136 файлов / 1 723 теста**, обе проверки TypeScript и production-сборка. `npm run notices` проверил **316 пакетов**; `THIRD_PARTY_NOTICES.md` не изменился. Сохраняется предупреждение Vite о размере JS-бандла.

Локальный архив macOS ARM64 прошёл установочный smoke: bundled runtime, lifecycle, несколько проектов, повторная установка, Trino CA и backup/restore. Все четыре перехода **0.2.0/0.2.1 → 0.7.0 × стандартные/нестандартные пути** прошли с сохранением ключей, подключений, SQL, досок и результатов.

## Публичная установка и обновление

На macOS ARM64 в отдельных временных каталогах прошли:

- Чистая и повторная установка через публичный `install.sh` без локального архива в положительных сценариях и без системного Node в PATH. Проверены запуск, несколько проектов, backup/restore и сохранение Trino CA.
- Все четыре онлайн-перехода **0.2.0/0.2.1 × стандартные/нестандартные пути → 0.7.0**. Сохранились подключения, секреты, ключ, SQL, доски и результаты; проверены отклонение неверной контрольной суммы и восстановление старой/новой копии.
- Реальный CLI-переход **0.6.0 → 0.7.0** через официальный GitHub Release. `update --check` сохранил работающий процесс; `update --to 0.7.0` сохранил пути, ключ и рабочую область. Схема SQLite осталась 5; доска, редактор, чат, история и зашифрованный профиль сохранились после запуска. Команда `miracle` работает в новой zsh после настройки PATH.
- `update --check` и `update` на актуальной 0.7.0 сохранили процесс и данные. Сохранение стрелки и исходников/данных кастомного графика после перезапуска подтверждено через API; этот сценарий не утверждает браузерную отрисовку.

Все три этапа публичной проверки завершились с кодом 0; последний — **6 ноября 2026 года, 06:27:48 UTC**. Сводка: `.local/release-0.7.0/public-summary.json`, `passed: true`. Журналы: `public-downloads.log`, `public-online.log`, `public-cli-update.log` и вложенные журналы в `public/`. Временные установки и проекты удалены после проверки; пользовательская установка не менялась.

## Границы подтверждения

Нативный Linux CI не подтверждает работу на Windows-хосте с WSL 2 и открытие адреса в браузере Windows. Проверка на таком хосте в этом выпуске не выполнена. Реальный Claude CLI, fish и мобильные устройства отдельно не проверялись. Полная матрица реальных ClickHouse/Trino/TLS-интеграций для этого выпуска не запускалась; отдельный UK-стенд использовал ClickHouse. Остальные ограничения Browser, данных и преобразований перечислены в [подробном отчёте](release-validation-0.7.0.md); локальный UK-датасет не входит в поставку.
