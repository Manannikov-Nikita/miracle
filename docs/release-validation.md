# Проверка Miracle 0.6.0

Публичная загрузка всех файлов и контрольные суммы подтверждены. Чистая установка и обновления через официальный выпуск прошли на macOS ARM64.

Изменения включены в `main` через [PR #6](https://github.com/Manannikov-Nikita/miracle/pull/6) **4 ноября 2026 года, 19:13:59 UTC**. Merge-коммит и тег `v0.6.0` указывают на `19f46aa4ea29f639e2f5c09124d51e305ca677c9`.

[Miracle 0.6.0](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.6.0) опубликован **4 ноября 2026 года, 19:49:49 UTC** (release ID `434376076`). В выпуск загружены четыре native-архива macOS/Linux, четыре файла SHA-256 и фиксированный `install.sh`.

## Что изменилось

- Чат принимает изображения через меню «+», вставку и перетаскивание. Добавлены автоапрув для отдельного чата и компактные согласования под ответом. PNG/JPEG/GIF/WebP передаются провайдерам нативно; лимит — четыре файла по 5 МиБ.
- Проводник показывает дерево проекта. Текстовые файлы можно создавать, редактировать и сохранять; Markdown использует живой редактор. SQL сохраняет свои средства запуска и работы с результатами.
- Запуск по датам получил календарь диапазона с днями, неделями и месяцами, вводом ISO-дат и переключением стрелками. После исчерпания попыток цикл приостанавливается; продолжение повторяет тот же период, сохраняя готовые результаты.
- Блоки копируются через Option/Alt + перетаскивание и Cmd/Ctrl+C/V, включая перенос между досками одного проекта.
- У графиков настраиваются оси, сетка, подписи, палитра и отдельные цвета серий. Shift при растягивании за угол сохраняет пропорции. Настройки и размеры доступны агенту через `board_patch` и справку `chart_guide`.

Подробные сценарии и результаты каждого этапа: [проверка 0.6.0](release-validation-0.6.0.md).

## Локальные проверки

На Node.js **24.22.2** выполнены:

- `npm test -- --maxWorkers=4`: **125 файлов, 1 548 тестов прошли** после исправления потокового разбора сообщений агента.
- `npm run build`: обе проверки TypeScript и production-сборка прошли. Осталось прежнее предупреждение Vite о размере JS-бандла.
- `npm run notices`: проверены 297 пакетов; `THIRD_PARTY_NOTICES.md` совпал с сохранённой версией. `git diff --check` прошёл.
- Native-архив macOS ARM64 прошёл установочный smoke: запуск bundled runtime без системного Node, несколько проектов, повторная установка, backup/restore и сохранение Trino CA.
- Все четыре локальных перехода **0.2.0/0.2.1 → 0.6.0 × стандартные/нестандартные пути** прошли. Проверены контрольные суммы, остановка старого процесса, ключ, секреты, SQL, доски, результаты и восстановление старых/новых копий.
- Отдельное обновление **0.5.1 → 0.6.0** подтвердило схему **4 → 5** и сохранение доски, редактора, чата и истории, шифрованного профиля и ключа. Установка кода не меняет SQLite до запуска приложения. Автоапрув существующего чата по умолчанию выключен; его включение сохраняется после перезапуска.

Установочные проверки использовали временные каталоги и синтетические данные. Пользовательская установка и рабочие проекты не менялись. Локальный тестовый стенд оставлен на `http://127.0.0.1:3060`.

Первый [CI 41883911419](https://github.com/Manannikov-Nikita/miracle/actions/runs/41883911419) прошёл Linux, но на macOS Intel большая история Codex превысила таймаут. Причина — повторное сканирование растущей строки на каждом фрагменте stdout. Для сообщения 33 МиБ старый разбор обрабатывал около 8,64 ГБ текста; после перехода к накоплению фрагментов время того же локального сценария сократилось с **3032 до 158 мс**. Размер фикстуры и таймаут не ослаблялись. Семь регрессий и независимая проверка 205 вариантов разбиения входа подтвердили UTF-8, лимиты, несколько сообщений и терминальные ошибки.

## Интерфейс и MCP

В браузере проверены вложения и согласования, панель чата на разных ширинах, дерево проекта и сохранение Markdown/JSON/SQL, создание файлов, календарные сценарии, копирование между досками и оформление графиков с повторным чтением сохранённых настроек. Реальный Codex CLI 0.153.0 получил тестовый PNG и правильно описал изображение.

Настоящий HTTP MCP в изолированном проекте подтвердил каталог инструментов, `chart_guide`, создание и изменение графика, сохранение осей/сетки/подписей/цветов и размеров, сброс, отклонение неверного HEX и конфликта ревизии. Изменение оформления не запускает SQL повторно.

Option/Shift с перетаскиванием покрыты компонентными событиями и проверками геометрии; достоверная автоматизация реального браузерного жеста с удерживаемым модификатором не подтверждена.

## Публичная установка и обновление

На macOS ARM64 в отдельных временных каталогах прошли:

- Чистая и повторная установка через публичный `install.sh` без `MIRACLE_ARCHIVE` в положительных сценариях и без системного Node в PATH. Проверены запуск, несколько проектов, backup/restore и сохранение Trino CA.
- Все четыре онлайн-перехода **0.2.0/0.2.1 × стандартные/нестандартные пути**. Сохранились подключения, секреты, ключ, SQL, доски и результаты; проверены отказ при неверной контрольной сумме и восстановление старой/новой копии.
- Реальный `miracle update` **0.5.1 → 0.6.0** через официальный GitHub Release. `--check` сохранил работающий процесс; обновление сохранило пути, ключ и рабочую область. Миграция 4 → 5 сохранила доску, редактор, чат и историю, ручной режим согласований по умолчанию и последующее сохранение автоапрува.
- Команды `update --check` и `update` на актуальной 0.6.0 сохранили процесс и данные.
- Сохранение стрелки и исходников/данных кастомного графика после перезапуска. Это API-проверка; браузерная отрисовка этим сценарием не подтверждается. Сценарий публичного CLI-обновления завершился **4 ноября 2026 года, 19:51:14 UTC**.

Все три этапа публичной проверки завершились с кодом 0; последний — **4 ноября 2026 года, 19:52:08 UTC**. Сводка: `.local/release-0.6.0/public-summary.json`, `passed: true`. Журналы: `public-downloads.log`, `public-online.log`, `public-cli-update.log` и вложенные журналы в `public/`. Временные установки и проекты удалены после проверки; пользовательская установка не менялась.

## Границы подтверждения

Реальный Claude CLI, Windows-хост с WSL 2, fish и мобильные устройства в этом выпуске не проверялись; транспорт Claude покрыт subprocess-тестами. Реальные ClickHouse/Trino/TLS-интеграции для 0.6.0 отдельно не запускались; их результаты 0.5.1 не являются новым прогоном этого выпуска.

Редактор файлов поддерживает UTF-8 до 2 МиБ; бинарный предпросмотр не включён. Копирование между досками ограничено одним проектом. Установочные проверки SQLite не подтверждают перенос браузерного localStorage: для старых SQL-черновиков нужен исходный origin.
