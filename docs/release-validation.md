# Проверка релизного комплекта 0.1.0 — 23 октября 2026

Локальная проверка выполнена на macOS Apple Silicon с Docker Desktop. После публикации исходников [GitHub Actions](https://github.com/Manannikov-Nikita/miracle/actions/runs/39945825472) успешно выполнил проверки на нативных Linux amd64/arm64 и проверку Windows-скриптов.

| Проверка | Результат |
| --- | --- |
| TypeScript + production build | Пройдены |
| Unit/API/component tests | 442 теста пройдены |
| Реальные PostgreSQL 17, ClickHouse 25.8, Trino 484 | 9 интеграционных групп пройдены |
| ClickHouse HTTPS / mTLS / CA / certificate authentication | Пройдены на отдельном контейнере с временным PKI |
| Чистая установка linux/arm64 | Пройдена в Docker на Apple Silicon |
| Чистая установка linux/amd64 | Пройдена под эмуляцией Docker; это не проверка Windows или Intel Mac |
| Первое создание администратора, повтор/истечение токена, гонка с CLI | API/integration/component проверки пройдены |
| Потеря блокировки при запуске | Воспроизведена ошибка, исправлена и покрыта регрессионным тестом |
| Копия / пустая установка / восстановление / обновление / отказ downgrade | Docker smoke; данные доски и ключи сохраняются |
| Потеря и подмена ключа | Docker smoke: отказ запуска без сброса БД; исходный ключ восстанавливает доступ |
| Browser | Одноразовая ссылка открывает мастер и очищается из адреса; форма восстановления ссылки; вход после восстановления; пустое состояние; оба подключения через host.docker.internal; SQL → таблицы → доска; перезапуск и повторное открытие снимков |
| Создание пароля в Browser | Ввод нового пароля вручную не выполнялся; создание администратора проверено API и компонентными тестами |
| ZIP | Строгий список файлов, фиксированный тег, SHA-256; GitHub CI собирает комплект для Manannikov-Nikita/miracle |

| Нативные Linux amd64 / arm64 | GitHub CI: тесты, сборка, реальные движки и TLS, образ, чистая установка, перезапуск, копия, восстановление, обновление и потеря ключа — пройдены на обеих архитектурах |

Полный ручной сценарий готового ZIP на Windows 11 x64, macOS Intel и отдельных Linux x64/ARM64 машинах пока не проверен. Автоматический CI не заменяет эту проверку на пользовательских компьютерах. Выпуск ранний; Windows ARM остаётся экспериментальным.

Тестовые установки, аккаунты и volumes изолированы от исходной рабочей области. После проверки временные контейнеры и данные удаляются; исходный development Compose и его volumes сохраняются.
