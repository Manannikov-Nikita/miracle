# Проверка Miracle 0.4.0

[Miracle 0.4.0](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.4.0) опубликован **1 ноября 2026 года**. Тег `v0.4.0` указывает на `53fed2a77e09af6ae8d2e64f238dc138b11b1d00`; изменения включены в `main`. Доступны четыре native-архива, четыре файла SHA-256 и `install.sh`.

## Состав выпуска

- Обновлённое оформление Soft Graphite, компактные панели и действия SQL, подключений и чата.
- Просмотр доски отделён от редактирования документа: камера, выделение, свойства и просмотр таблиц не создают сохранений и конфликтов.
- Непрерывная прокрутка тачпадом через графики и таблицы.
- Свободные стрелки, повторная привязка к блокам, изменение изгиба, подпись на линии, компактное меню оформления и видимые точки крепления при выделении.
- Сообщения об ошибках с причиной, предложением исправления и раскрываемыми техническими подробностями.

## Локальные проверки

На macOS arm64 с фиксированным Node.js 24.22.2:

- `npm ci` завершился; зависимости установлены из lockfile.
- `npm test`: **1117 тестов в 91 файле**, все прошли.
- `npm run build`, включая оба TypeScript-проекта: прошёл. Сохраняется прежнее предупреждение Vite о размере клиентского чанка.
- `npm run notices`: 297 пакетов; `THIRD_PARTY_NOTICES.md` не изменился.
- `git diff --check`: прошёл.
- Проверка в браузере: изменение изгиба угловой и плавной стрелки, переход прямой в кривую одним жестом, отмена, компактная палитра. При выборе блока или стрелки видны все 36 точек девяти блоков; без выделения они скрыты.
- Независимое ревью серверной совместимости, операций сохранения и frontend: блокирующих замечаний нет.

- Native smoke: чистая установка, запуск/остановка, несколько проектов, переустановка, Trino HTTPS CA и backup/restore прошли без системного Node.
- **4/4 обновления** с опубликованных 0.2.0/0.2.1 со стандартным и пользовательским хранилищем прошли; ключи, подключения, SQL, результаты и доски сохранены, старые и новые резервные копии восстанавливаются.

## GitHub Actions

[Release workflow 41324223483](https://github.com/Manannikov-Nikita/miracle/actions/runs/41324223483) завершился успешно и автоматически опубликовал файлы. macOS Intel/Apple Silicon и GNU/Linux x64/ARM64 прошли тесты, сборку, установочный smoke и матрицу обновлений со старых версий.

Первый запуск Linux x64 остановился на гонке старого тестового стенда `agent-mcp-integration`: файл `capability.json` стал видимым до завершения записи. Повторное выполнение этого задания на том же неизменённом коммите прошло. Тег не переносился, опубликованные assets не заменялись.

## Публичные проверки после выпуска

- Анонимно скачаны все четыре архива и их контрольные суммы. SHA-256 и размеры совпали с файлами `.sha256` и metadata GitHub.
- Установщик `latest` совпал с установщиком фиксированного `v0.4.0`; его размер и SHA-256 совпали с metadata GitHub.
- На macOS arm64 прошли чистая онлайн-установка, переустановка и **4/4 онлайн-обновления** с 0.2.0/0.2.1 со стандартными и пользовательскими путями. Установщик сам скачивал опубликованный архив; локальная подмена `MIRACLE_ARCHIVE` для кандидата не использовалась.
- Реальный `miracle update` обновил установленную **0.3.1 → 0.4.0**. Предварительный `--check` сохранил работающий процесс. Обновление сохранило рабочую область, доску, ключ шифрования и пользовательские пути установки. Новый zsh нашёл команду `miracle`.
- На установленной 0.4.0 команды `update --check` и `update` сообщили об актуальной версии, сохранив работающий процесс и данные.
- Свободная стрелка с ручным изгибом, положением подписи и оформлением сохранилась после перезапуска опубликованной 0.4.0.

Установочные проверки выполнялись во временных каталогах; пользовательская установка и проекты не менялись.

## Границы проверки

Реальные удалённые ClickHouse/Trino не прогонялись заново; локальные HTTP/TLS тесты входят в полный набор. Реальные WSL, fish и Claude CLI отдельно не проверялись. Приложение предназначено для ПК, мобильная вёрстка не проверялась.
