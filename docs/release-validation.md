# Проверка Miracle 0.4.0

Кандидат **0.4.0** подготовлен из ветки `codex/soft-graphite`. Исходные `main` и `origin/main` совпадали: `8915015`. Публичный выпуск на момент подготовки — 0.3.1; тег и файлы 0.4.0 ещё не опубликованы.

## Состав выпуска

- Обновлённое оформление Soft Graphite, компактные панели и действия SQL, подключений и чата.
- Просмотр доски отделён от редактирования документа: камера, выделение, свойства и просмотр таблиц не создают сохранений и конфликтов.
- Непрерывная прокрутка тачпадом через графики и таблицы.
- Свободные стрелки, повторная привязка к блокам, изменение изгиба, подпись на линии, компактное меню оформления и видимые точки крепления при выделении.
- Сообщения об ошибках с причиной, предложением исправления и раскрываемыми техническими подробностями.

## Локальные проверки

На macOS arm64 с фиксированным Node.js 24.22.2:

- `npm ci` завершился; зависимости установлены из lockfile.
- `npm test`: **1117 тестов в 91 файле**, все прошли.
- `npm run build`, включая оба TypeScript-проекта: прошёл. Сохраняется прежнее предупреждение Vite о размере клиентского чанка.
- `npm run notices`: 297 пакетов; `THIRD_PARTY_NOTICES.md` не изменился.
- `git diff --check`: прошёл.
- Проверка в браузере: изменение изгиба угловой и плавной стрелки, переход прямой в кривую одним жестом, отмена, компактная палитра. При выборе блока или стрелки видны все 36 точек девяти блоков; без выделения они скрыты.
- Независимое ревью серверной совместимости, операций сохранения и frontend: блокирующих замечаний нет.

- Native smoke: чистая установка, запуск/остановка, несколько проектов, переустановка, Trino HTTPS CA и backup/restore прошли без системного Node.
- **4/4 обновления** с опубликованных 0.2.0/0.2.1 со стандартным и пользовательским хранилищем прошли; ключи, подключения, SQL, результаты и доски сохранены, старые и новые резервные копии восстанавливаются.

CI четырёх платформ и публичные загрузки будут зафиксированы после завершения. До этого локальная сборка не считается подтверждением публикации.

## Границы проверки

Реальные удалённые ClickHouse/Trino не прогонялись заново; локальные HTTP/TLS тесты входят в полный набор. Реальные WSL, fish и Claude CLI отдельно не проверялись. Приложение предназначено для ПК, мобильная вёрстка не проверялась.
