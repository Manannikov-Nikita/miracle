# Проверка Miracle 0.9.0

[Miracle 0.9.0 опубликован](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.9.0) **07.11.2026, 12:39:59 МСК**. Все три поддерживаемые платформы прошли CI. Анонимное скачивание, чистая онлайн-установка и настоящее обновление 0.8.1 → 0.9.0 подтверждены.

## Изменения

Индикаторы SQL и саб-агентов в чате, ответы на вопросы, Steer без остановки текущего хода, подсветка SQL и открытие запуска в редакторе. Исправлены повторные уведомления об исторических SQL-ошибках, полосы прокрутки вокруг колец и показ паузы среди активных запусков. Новый общий колор-пикер и настройки сохранённых цветов. SQLite мигрирует со схемы 5 на 6, сохраняя существующие данные.

## Проверки функций

- Релизный прогон Node 24.22.2: **169 файлов / 2155 тестов**, все прошли (`.local/release-0.9.0/tests-release-final.log`). Первоначальный прогон выявил тест, не ожидавший отложенного возврата фокуса Radix; проверка теперь ждёт фактического фокуса.
- `npm run build`: client/server TypeScript и production-сборка прошли (`build.log`). Сохраняется предупреждение Vite о размере bundle. `npm run notices`: 316 пакетов, notices без изменений; `git diff --check` прошёл.
- Нативный архив macOS ARM64 собран с проверкой Node SHA-256 (`archive.log`). Чистая/повторная установка, bundled runtime без системного Node, lifecycle, несколько проектов, Trino HTTPS CA и backup/restore прошли (`install.log`).
- Обновление **0.8.1 → 0.9.0** прошло для проектного и нестандартного хранилища: schema 5 → 6, таблица `agent_query_runs`, сохранение ключа/секретов/SQL/доски/результатов/редактора, check-only, ошибки загрузки/checksum, no-op и backup/restore (`upgrade.log`). До публикации сетевой транспорт обновления использовал локальные проверенные артефакты только в тестовом процессе.
- Реальный Codex CLI: вопросы, Steer, два саб-агента и SQL-запуски по датам проверены на синтетическом стенде. Протокольные фикстуры Codex/Claude покрывают ответы, разрешения, изоляцию чатов и отмену.
- Браузер: кольца при вращении/разных счётчиках, пауза и продолжение, SQL-превью и редактор, отсутствие повторных исторических ошибок. Колор-пикер: HSV-перетаскивание, RGB, сохранение/имена/порядок, перезагрузка, вложенный Escape, возврат фокуса, размеры 1280/375/320 px.
- Независимое ревью пикера выявило отклонённое редактирование и потерю HSL-оттенка на сером; оба исправлены с регрессиями. Черновик имени сохраняется при обновлении из другой вкладки.
- Палитра хранится в localStorage текущего origin: проекты на разных портах имеют отдельные палитры. Формат цветов документов остаётся #RRGGBB; непрозрачность фигуры регулируется отдельно.

## Границы подтверждения

Реальный Claude CLI, Windows/WSL-хост и полная матрица внешних ClickHouse/Trino/TLS не проверялись заново в этом выпуске. EyeDropper доступен по возможностям браузера; отмена и поздний результат покрыты тестами, физический выбор системного пикселя отдельно не подтверждён.

Запрошенный ранее Codex Security scan не стартовал из-за неподдерживаемого `.codegraph/daemon.sock`; полноценный отчёт аудита безопасности не сформирован. Проверки разработки и независимое ревью не заменяют этот аудит.
