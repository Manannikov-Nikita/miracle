# Проверка и публикация Miracle 0.3.1

[Miracle 0.3.1](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.3.1) опубликован **1 ноября 2026, по Москве**. `releases/latest` указывает на 0.3.1; доступны четыре архива macOS/Linux, четыре файла SHA-256 и `install.sh`.

Тег `v0.3.1` указывает на коммит `765420f3cbfd7e42e5e9616b5bf655d9cbc0d843`. [Workflow 41249821355](https://github.com/Manannikov-Nikita/miracle/actions/runs/41249821355) прошёл на всех четырёх платформах и автоматически опубликовал проверенные файлы. Исходная `main` перед работой совпадала с `origin/main`, коммит `3299426`.

## Что изменилось

Установщик предлагает сохранить каталог команды в PATH. Он читает согласие из терминала и работает при `curl | sh`; отказ и неинтерактивный запуск оставляют настройки без изменений. Явное `MIRACLE_MODIFY_PATH=yes` позволяет сохранить настройку после временного `export PATH`. Данные проектов и программа устанавливаются независимо от успеха необязательной настройки оболочки.

## Локальные проверки

На macOS arm64 с Node.js 24.22.2:

- `npm test`: **835 тестов в 75 файлах**, все прошли. Добавлены 16 сценариев настройки PATH: zsh, Bash login/non-login, sh, собственный ZDOTDIR, экранирование пути, сохранение существующего профиля, повторная установка, CI/отсутствие терминала, отказ и ошибки записи.
- `npm run build`, включая typecheck обоих TypeScript-проектов: прошёл. Сохраняется прежнее предупреждение Vite о размере клиентского чанка.
- Настоящий установщик из архива проверен в псевдотерминале с piped stdin: Enter отклоняет настройку, `y` сохраняет её, до согласия профиль не меняется. Во время вопроса блокировка установки уже освобождена. Новый zsh находит `miracle`.
- Native smoke: чистая установка, запуск/остановка, несколько проектов, переустановка, Trino HTTPS CA и backup/restore прошли.
- **4/4 обновления** настоящих 0.2.0/0.2.1 со стандартным и пользовательским хранилищем прошли; проверены ключи, данные, SQL, доски, результаты, API импорта черновиков и восстановление копий.

## Публичные проверки после выпуска

Анонимно скачаны все четыре архива и контрольные суммы. SHA-256 и размеры совпали с соседними `.sha256` и GitHub API. Установщик `latest` совпадает с установщиком `v0.3.1` и шаблоном из тега.

На macOS arm64 проверены:

- Чистая онлайн-установка и переустановка; положительные сценарии запускают публичный установщик без `MIRACLE_ARCHIVE`.
- **4/4 онлайн-обновления** с 0.2.0/0.2.1, включая сохранение данных и ключей, остановку прежнего процесса и восстановление копий.
- Настоящий `curl | sh` в псевдотерминале: согласие и отказ; новый терминал находит команду после согласия.
- Реальный `miracle update` **0.3.0 → 0.3.1**. Проверка `--check` сохраняет работающий процесс, обновление скачивает официальный установщик и архив, останавливает свой сервер и сохраняет пользовательские пути, ключ шифрования и доску. После запуска сохраняется идентификатор рабочей области; новый zsh выполняет `miracle --version`.
- `miracle update --check` и `miracle update` на установленной 0.3.1 сообщают, что версия актуальна, сохраняя процесс и данные.

Проверки выполнялись во временных каталогах и shell-профилях, которые удалены после завершения. Пользовательская установка не менялась.

## Границы проверки

Нативный CI проверил macOS Intel/Apple Silicon и GNU/Linux x64/ARM64. Отдельного запуска на Windows/WSL и проверки fish в реальной оболочке не было. Интеграции с реальными ClickHouse/Trino заново не выполнялись для исправления PATH; результаты предыдущей версии сохранены отдельно. Claude CLI остаётся непроверенным на настоящем бинарнике. Мобильная вёрстка не проверяется: приложение предназначено для ПК.
