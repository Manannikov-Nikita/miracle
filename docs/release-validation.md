# Проверка Miracle 0.10.0

Кандидат готовится к публикации. Последний опубликованный выпуск — [0.9.0](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.9.0); его подтверждённые результаты сохранены в [отдельном отчёте](release-validation-0.9.0-public.md). Результаты CI и публичных загрузок будут добавлены после фактического завершения.

## Изменения

Универсальный поиск по проекту с ранжированием и вкладками типов; переход к совпадению без потери черновика. Модели и уровни рассуждений отдельно для каждого чата. Самостоятельные линии и поворот фигур. Итоги столбцов с накоплением, хронологическая сортировка дат, выравнивание SQL-алиасов. Обновление открытого кода после работы агента, явное прикрепление контекста, анимация границы и локализация действий. Пустые состояния и управление панелями. SQLite переходит со схемы 6 на 7 для настроек моделей.

## Проверки кандидата

- Логи находятся в `.local/release-0.10.0`.
- Полный прогон Node 24.22.2: **190 файлов / 2441 тест**, все прошли (`tests-final.log`). Исправлены две найденные регрессии: фикстура v4 больше не сохраняет колонки v7; стабильный callback истории устраняет лишние рендеры карточек при перетаскивании.
- Production build и TypeScript прошли. Предупреждение Vite о размере bundle сохраняется. Notices: 316 пакетов, файл лицензий без изменений.
- Нативный архив macOS ARM64 собран с проверенным Node 24.22.2. Чистая установка, lifecycle, backup/restore и запуск без системного Node прошли (`install.log`).
- Обновление опубликованной 0.9.0 до кандидата 0.10.0 прошло для project/custom storage: схема 6 → 7, сохранность запросов, досок, результатов, редактора, профиля и истории чата; настройки моделей, восстановление старой/новой копии, отказ при неверной checksum и отсутствие изменений при неудаче (`upgrade.log`).
- Независимые ревью клиента, сервера и shared-кода не нашли оставшихся блокирующих проблем. Профильные проверки: 113 серверных тестов и 41 тест перетаскивания, трансформаций и блокировок.
- UI новой функциональности проверялся на настольном экране. Модельный каталог получен от подключённого Codex, проверены зависимые уровни рассуждений и клавиатурный выбор; для этой проверки модельные запросы не запускались.

## Границы подтверждения

Реальный Claude CLI, Windows/WSL-хост и полная матрица внешних ClickHouse/Trino/TLS не проверялись заново. Claude покрыт протокольными фикстурами. Для пользовательского `--settings` в Claude каталог моделей недоступен; обычный запуск профиля остаётся прежним. Парсер дат поддерживает UTC/Z и числовые смещения, но не суффиксы часового пояса IANA в строковых значениях. Отдельный аудит безопасности для выпуска не выполнялся.
