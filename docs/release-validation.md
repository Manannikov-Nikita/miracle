# Проверка Miracle 0.11.0

Сборка подготовлена 10 ноября 2026 года и проверена локально. Пользователь подтвердил публикацию; результаты GitHub CI и проверка публичных файлов будут добавлены после выпуска. [Отчёт 0.10.0 сохранён отдельно](release-validation-0.10.0-public.md).

## Что вошло

Изображения на досках и слайдах; корректное отображение YAML-метаданных Markdown; создание папок и перенос файлов с сохранением черновиков; эскиз переноса объектов поверх панелей; автоматическое использование доверенных CA системы и Node с ручным PEM; копирование таблиц в Markdown; favicon с логотипом Miracle. [Подробности](release-0.11.0.md).

Изображения хранятся в проектной SQLite, схема 7 → 8. Они сохраняются при копировании блоков и backup/restore. Автоматический TLS использует уже доверенные сертификаты и сохраняет проверку имени сервера; вручную заданный CA имеет приоритет для конкретного подключения.

## Проверки кода и интерфейса

- Node 24.22.2, полный Vitest перед публикацией: **195 файлов / 2500 тестов, все прошли** (`.local/release-0.11.0/tests-publication.log`).
- TypeScript и production build прошли (`build-publication.log`). Сохраняется предупреждение Vite о размере основного bundle. Лицензии: 316 пакетов, notices без изменений.
- Независимые ревью серверной и клиентской части завершены без оставшихся существенных замечаний (`final-review.md`, `root-review.md`, `canvas-review.md`). Найденные проблемы исправлены: потеря пользовательского жеста при асинхронном clipboard write, устаревшие строки при повторном копировании растущего SQL-результата, смещение дерева при drag и быстрый drop. По последующему замечанию пользователя кнопка корня удалена; выбор корня и перенос доступны через свободную область дерева.
- Регрессионные проверки покрывают валидацию и хранение изображений, сохранность бинарных данных при backup/restore, пути/симлинки/коллизии/блокировки при работе с файлами, черновики и запоздавшие ответы, метаданные Markdown с BOM/CRLF, экранирование и полное копирование таблицы, корректную отмену переноса и TLS с синтетическими сертификатами.
- Desktop UI проверен через **@Browser**, на отдельном временном проекте: YAML-метаданные остаются исходным текстом, тело Markdown отображается; папка создаётся; открытый SQL с изменениями переносится между папками и в корень; изображение загружается на доску, копируется в презентацию и показывается в полноэкранном режиме; Markdown из буфера вставляется в файл и отображается таблицей; доступны автоматические CA и ручной PEM; подключён favicon.
- Нестабильные тесты custom chart исправлены после воспроизведения: вместо фиксированной задержки они ждут наблюдаемого результата WebCrypto и всегда завершают активный запуск (`timing-report.md`).

После уточнения навигации в @Browser повторно проверены отсутствие кнопки, создание в выбранной папке и корне, сброс выбора через фон/Escape и перенос файла папка → корень через свободную область. Открытый редактор сохраняется. Профильные тесты дерева и создания файлов: **27 тестов прошли** (`tree-navigation-tests.log`); TypeScript и production build повторены после правки. Регрессии также проверяют сброс подсветки на недоступной цели переноса.

Для вставки изображений дополнительно проверены оба представления буфера (files/items), отсутствие дублей, неактивная панель и текстовые поля: **34 теста прошли** (`image-paste-green.log`). В @Browser PNG вставлен обычным ⌘V отдельно на доску и в презентацию, изображения сохранились после перезагрузки.

## Локальный архив

Архив macOS ARM64 с собственным Node 24.22.2 находится в `.local/release-0.11.0/candidate/`, рядом — SHA-256 и `install.sh`. Сборщик копирует только разрешённые файлы приложения; пользовательские проекты и данные не включаются.

- Чистая установка окончательного архива прошла: запуск без системного Node, lifecycle, несколько проектов, повторная установка, отдельное хранилище, приватные файлы, CA Trino и backup/restore (`install.log`).
- Обновление опубликованной 0.10.0 до окончательного архива 0.11.0 прошло для project/custom storage: схема 7 → 8; сохранены запросы, доски, результаты, редактор, профиль, чаты, история, настройки моделей и секреты; проверены старые и новые резервные копии, отказ при неверной checksum/скачивании, отсутствие изменений при повторном обновлении (`upgrade.log`). Все проекты синтетические и временные.
- Checksum повторно сверена с архивом; favicon присутствует внутри. Размер: **49 593 937 байта**. SHA-256: `996a48f8b746b922585836da5cea9281340a3dbcd4359b32d74da95702714984`.
- Исходные изменения оставлены в локальной ветке `codex/release-0.11.0`. [Установка и обновление](release-0.11.0.md#установка-и-обновление).

## Границы подтверждения

Для этого локального кандидата собран и проверен macOS ARM64. Linux, Windows/WSL, реальные корпоративные ClickHouse/Trino и реальный Claude CLI заново не проверялись. TLS проверен локальными HTTPS-серверами с разными цепочками доверия; мобильные устройства не тестировались. Отдельный аудит безопасности не выполнялся.

Копирование таблиц использует существующие ограничения API снимков: 50 000 строк, 20 MiB, 1 000 000 ячеек; при превышении возвращается ошибка, а не усечённая таблица.
