# Проверка Miracle 0.8.1

Подготовка завершена локально **7 ноября 2026 года**. Публикация и результаты GitHub CI ещё не подтверждены.

Изменения: поддержка macOS Apple Silicon (ARM64), GNU/Linux ARM64/x64; актуальные инструкции установки и встроенного обновления, исключение устаревших выпусков без команды `miracle update` из раздачи и CI. На macOS x64 установщики отказывают до загрузки и изменения установки.

## Локальные проверки

- Node.js **24.22.2**: **158 файлов / 2 039 тестов** прошли. Журнал: `.local/release-0.8.1/tests-final.log`.
- `npm run build`: обе проверки TypeScript и production-сборка прошли. Сохраняется предупреждение Vite о размере клиентского bundle. Журнал: `.local/release-0.8.1/build.log`.
- `npm run notices`: **316 пакетов**, `THIRD_PARTY_NOTICES.md` без изменений. `git diff --check` прошёл.
- Нативный архив macOS ARM64 собран с проверкой SHA-256 Node runtime. Чистая и повторная установка без системного Node, несколько проектов, lifecycle, Trino HTTPS CA, private state и backup/restore прошли. Журналы: `.local/release-0.8.1/archive.log`, `.local/release-0.8.1/install.log`.
- Регрессии проверяют отказ macOS x64 в сборщике, shell bootstrap и прямом установщике, а также публикацию только трёх обязательных пар архив/контрольная сумма.

- Обновление опубликованной **0.8.0 → кандидат 0.8.1** через реальный CLI прошло для обычного и нестандартного хранилища, включая Trino TLS fixture. Проверены check-only, ошибки загрузки и checksum, остановка своего процесса при активации, сохранение ключей/секретов/SQL/доски/результата/редактора и старого origin, восстановление старой и новой копии, no-op актуальной версии. До публикации официальные сетевые ответы заменялись локальными артефактами только в тестовом процессе.
- Независимое ревью не нашло блокирующих замечаний. Проверка нового `miracle update` через настоящие публичные GitHub URL выполняется после публикации.

## Границы подтверждения

Локальная проверка macOS ARM64 не заменяет Linux CI. Реальный Windows/WSL-хост, Claude CLI, мобильный браузер и полная матрица внешних ClickHouse/Trino/TLS в этом maintenance-выпуске отдельно не проверяются.

Сохраняются ранее известное предупреждение о размере JS bundle и low advisory вложенного KaTeX, описанные в [проверке предыдущего выпуска](release-validation-0.8.0-public.md). Зависимости в этом выпуске не менялись.

История предыдущего выпуска: [публичная проверка 0.8.0](release-validation-0.8.0-public.md), [функциональная проверка 0.8.0](release-validation-0.8.0.md).
