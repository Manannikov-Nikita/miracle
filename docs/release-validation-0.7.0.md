# Проверка Miracle 0.7.0

Состояние на **6 ноября 2026 года**: [Miracle 0.7.0 опубликован](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.7.0). Все четыре платформы прошли CI; публичная установка и обновления подтверждены. Merge-коммит и тег: `4f773b33bf8f1c94f788c8694ae49e2807442db6`. Происхождение архивов, SHA-256 и результаты публикации: [сводный отчёт](release-validation-0.7.0-public.md). Ниже сохранены функциональные проверки выпуска.

## Состав выпуска

- Одиночный SQL показывает текущее и окончательное время, включая повторно открытые запуски. Серия по датам оценивает остаток по среднему времени завершённых дат; паузы исключены. До первой измеренной даты показывается пояснение, после завершения или остановки прогноз скрывается.
- Автокомплит ищет подстроку без учёта регистра, с приоритетом начала имени и более контрастной подсветкой. Это распространяется на составные агрегаты ClickHouse. Контекст SQL, диапазоны вставки и ограничения каталога сохранены.
- Поиск источников подсвечивает совпадения в подключениях, каталогах, схемах, таблицах, столбцах и типах. Переключатель полных названий включает перенос длинных имён; сохраняются Unicode-графемы и фильтрация по составным именам.
- LaTeX `$…$` и `$$…$$` работает в Markdown-файлах, блоках доски, таблицах и сообщениях агента. Клик в редакторе раскрывает исходник; код остаётся буквальным. KaTeX использует локальные CSS/шрифты, `trust: false` и ограничения расширений/размера.
- Стикеры показывают центрированный текст с автоматическим подбором размера 14–56 px. Очень длинный текст прокручивается. Убраны заголовок, настройки и внутренняя рамка; удаление и перетаскивание сохранены.
- В чате исправлены первое открытие и переключение меню. Обработанные разрешения группируются в свёрнутую строку со счётчиком; ожидающие решения запросы сохраняют кнопки ответа. Убраны верхние служебные подписи.
- Фокус прилегает к границам элементов. Убраны нижние панели доски и обозревателя; кнопки диалога сохранения помещаются внутри формы.
- Легенда настраивается восемью иконками положения с клавиатурным управлением. Подстановка `NULL` объединена с общими правилами значений; цвет расположен в заголовке правила, номера не повторяются в полях.
- Добавлены melt и pivot без агрегации. Сводная с расчётом остаётся отдельным режимом. Повторные пересечения pivot дают явный конфликт, включая одинаковые значения; несколько ключей строк позволяют его устранить.
- Представление таблицы используется обычными и кастомными графиками того же блока: фильтры, сортировка, порядок/видимость/названия столбцов, сводная, melt и pivot. Подстановки и числовое оформление используются в подписях и подсказках; координаты сохраняют исходные числа. Кастомный API получает преобразованные raw rows, displayRows и cellColors.
- При перетаскивании сохраняются ссылки на неизменные узлы и исключаются лишние обновления содержимого карточек. Частые записи локального черновика объединяются; завершение жеста и переходы жизненного цикла сохраняют последнее состояние.
- Проверка Codex после версии и справки выполняет `initialize → initialized → config/read` с текущим каталогом проекта. Модель и инструменты не запускаются. Ошибки конфигурации показываются до начала сообщения; успех в UI требует фактической проверки текущей команды.

## Локальная проверка исходников

Последний полный прогон перед подготовкой публикации на **Node.js 24.22.2**:

- `npm test`: **136 файлов, 1723 теста прошли**. Журнал: `.local/release-0.7.0/release-tests.log`.
- `npm run build`: обе проверки TypeScript, Vite и сборка сервера прошли. Журнал: `.local/release-0.7.0/release-build.log`. Сохраняются предупреждения сборщика о крупном JS bundle и аннотациях зависимостей.
- `npm run notices`: проверены 316 пакетов, `THIRD_PARTY_NOTICES.md` совпал с сохранённой версией. `git diff --check` и проверка форматирования изменённых компонентов прошли. Версия в обоих манифестах и корневой записи lockfile совпадает с 0.7.0.
- Независимые проверки модели таблиц, интеграции графиков, перетаскивания и конфигурации Codex не оставили замечаний. Найденные регрессии исправлены и покрыты тестами.

Новые проверки охватывают идентичность узлов, актуальность действий карточек, отмену перетаскивания, запись последнего черновика при смене доски, конфликте, HTTP/SSE-подтверждении и закрытии страницы. Проверки Codex включают ошибку загрузки конфигурации, ограничение времени в 8 секунд, отмену и завершение процесса, скрытие секретов, каталог проекта и отсутствие запуска потока модели. Отдельная UI-регрессия проверяет видимое пояснение ошибки и скрытие устаревшей надписи о готовности.

Первоначальные запуски в ограниченной среде не могли открыть тестовые порты (`listen EPERM`); повторение с доступом к локальным портам прошло. Системный Node 25 ранее выявлял несовместимость экспериментального Web Storage с тестовым окружением; итоговые проверки выполнены на поставляемом Node 24.

### Измерение перетаскивания

На отдельной UK-доске с **30 блоками и 10 графиками** выполнены два движения до и после оптимизации. Суммарное время React-отрисовки составило **117,7/150,0 мс → 38,6/39,5 мс**, то есть на 71% меньше для этих двух замеров. Максимальное время одного обновления — **19,1/22,7 мс → 5,5/5,8 мс**. Медиана расчёта выравнивания осталась около **0,1 мс**, поэтому его поведение не менялось.

Это измерения локальной development-сборки на конкретной доске, не гарантия FPS для всех устройств. Тестовые перемещения и растягивание отменены; временные измерители удалены. Данные: `.local/release-0.7.0/drag-diagnostics/browser-probes.json` и `browser-probes-after.json`; итоговый снимок `verified-after.jpg` в том же каталоге.

## Совместимость и границы

- Исходные результаты SQL сохраняются. Оформление и преобразования применяются к представлению блока; независимые копии блока имеют независимые настройки.
- `NULL`, числовые строки высокой точности, логические и составные значения не подвергаются неявному числовому преобразованию. Смешанные типы melt получают безопасную метаинформацию. Pivot не выбирает произвольное значение при конфликте.
- Полный снимок ограничен 50 000 строками, 20 MiB и 1 000 000 исходных ячеек. Преобразования — 1 000 000 выходных ячеек и 200 столбцов значений pivot. Лимиты графиков проверяются после преобразования.
- Старый `nullText` сохраняет прежний приоритет до редактирования подстановок; просмотр или изменение других настроек не переписывают правила. Старые вертикальные легенды в углах сохраняют ориентацию до явного выбора нового положения.
- Для кастомных графиков добавлен POST с TableSpec; прежний GET остаётся доступным. `decimal.js` включён в production-зависимости для поставляемой установки.
- Выбор совместимого Codex CLI относится к локальному профилю демо. Miracle не заменяет автоматически модель, reasoning или общую конфигурацию пользователя.
- Синтетический источник на порту 3072 используется только для таймеров. UK-датасет, ClickHouse и storytelling-доска — отдельный локальный стенд; они не входят в релизные архивы.
