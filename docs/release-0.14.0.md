# Miracle 0.14.0 — агенты на доске и проверка SQL

## Работа агента с доской

- Агент видит реальные границы фигур с учётом поворота, соседние объекты, расстояния и соединения. Перемещение, выравнивание, изменение размера и распределение выполняются пакетно с проверкой актуальной ревизии.
- Независимые изменения можно поручать двум исполнителям одновременно на текущем профиле и модели. У каждого свой цвет и имя на объектах и в списке исполнителей. Пересекающиеся участки ожидают очереди, отмена одного исполнителя не останавливает остальных.
- Содержимое блоков читается по необходимости; компактная сцена и краткие итоги сокращают контекст. Выбранная соединительная стрелка передаётся в чат вместе с выделенными блоками.
- Исполнители ограничены назначенными объектами через Miracle MCP. Это не отдельная песочница ОС для произвольных CLI-обёрток и сторонних MCP-серверов.

## SQL и таблицы

- SQL-редактор подчёркивает повторные алиасы, вероятное перекрытие исходного поля алиасом и пропущенные поля группировки. Подсказка при наведении объясняет исправление. Проверка локальная, учитывает диалект ClickHouse/Trino и не мешает запуску запроса; она не заменяет проверку сервером базы данных.
- Развёрнутая таблица занимает область доски. Исходные значения SQL-снимка выделены цветом и защищены от редактирования. Ручные строки и вычисляемые столбцы добавляются кнопками по краям таблицы.
- Настройки выбранного столбца открываются сбоку по клику на его название; SQL-выражение редактируется в большом редакторе. Обычный вид таблицы с форматированием и pivot сохраняется отдельно от режима формул.

## Обновление

```sh
miracle update --check
miracle update --to 0.14.0
```

Переход с 0.13.1 сохраняет проекты и схему SQLite 8; новая миграция не требуется. Проекты схемы 9 из 0.12.0-beta.1 по-прежнему несовместимы со стабильной веткой.

Архивы включают Node.js 24.22.2 и DuckDB. Доступны macOS Apple Silicon (ARM64), GNU/Linux ARM64/x64; Windows запускается через WSL 2. Платные вызовы моделей, реальные корпоративные базы и Windows/WSL в этом цикле не проверялись.
