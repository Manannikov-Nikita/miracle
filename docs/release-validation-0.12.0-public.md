# Проверка Miracle 0.12.0

[Стабильный выпуск 0.12.0](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.12.0) опубликован 12 ноября 2026 года в 00:30:08 МСК (11 ноября, 21:30:08 UTC). [PR #15](https://github.com/Manannikov-Nikita/miracle/pull/15) влит в `main`; тег `v0.12.0` указывает на коммит `dfb355190e6b006c13f75a10f308ba6c43880e1a`. Выпуск подготовлен на основе стабильной 0.11.1. [Её публичный отчёт сохранён отдельно](release-validation-0.11.1-public.md). [Состав выпуска и совместимость](release-0.12.0.md).

## Изменения и границы

Thinking Orbs в круглой кнопке свёрнутого работающего агента, состав контекста над полем ввода и лента действий в чате на основе Pasta UI. Точные общие значения контекста поступают от провайдера; оценочные категории обозначены «≈». Лента раскрыта во время работы и сворачивается после завершения. Результаты инструментов, ошибки, отмена и неизвестный итог различаются.

Схема SQLite остаётся 8. DuckDB, датасеты и схема 9 из 0.12.0-beta.1 не включены. Проекты схемы 9 нельзя открывать этим выпуском; автоматического обратного преобразования нет. Установщик считает стабильную 0.12.0 новее одноимённой беты, поэтому использовать обычное обновление для установки с такими проектами нельзя.

## Локальные проверки до публикации

- Полные локальные прогоны на закреплённом Node 24.22.2 и на Node 25.8.1: **205 файлов / 2609 тестов, все прошли**. Для Node 25 отключён экспериментальный webstorage для jsdom. Предупреждения jsdom об отсутствии canvas не влияют на результат.
- TypeScript клиента и сервера, production build прошли. Сохраняется предупреждение Vite о размере bundle.
- Независимое ревью не выявило блокирующих замечаний: события провайдеров, сохранение и сброс контекста, гонки GET/SSE и steer, границы запусков и жизненный цикл действий.
- Desktop-проверка: анимация свёрнутого агента, раскрытие контекста вверх, работа с длинным черновиком, активная/завершённая лента, ручное сворачивание и повторное открытие истории, подробности с клавиатуры, сохранение позиции прокрутки.
- Собран нативный архив macOS ARM64 с Node 24.22.2. Чистая установка, lifecycle нескольких проектов, backup/restore, Trino HTTPS с тестовым CA, приватность файлов и запуск без системного Node прошли.
- В отдельном тестовом проекте запущен стенд 0.12.0; установленный Codex 0.167.0 прошёл проверку запуска и загрузку каталога моделей. Реальный платный запрос агенту в рамках проверки не выполнялся.

Нативный переход с публичной 0.11.1 на кандидат 0.12.0 через CLI прошёл: схема 8 → 8, сохранность данных, ключей, запросов, досок, результатов, настроек агента и истории чатов; ошибки скачивания/checksum и повторное обновление не меняют данные и PID; восстановление старых и новых копий работает. В этой проверке транспорт обновления подставлял локальные файлы кандидата в официальный путь; фактический сетевой переход после публикации проверен отдельно ниже.

## CI и публикация

- [Проверки ветки релиза перед слиянием](https://github.com/Manannikov-Nikita/miracle/actions/runs/43101316923), запущенные вручную через `workflow_dispatch`, завершились успешно на macOS ARM64, Linux ARM64 и Linux x64.
- [Проверки `main`](https://github.com/Manannikov-Nikita/miracle/actions/runs/43102579864) прошли на тех же трёх платформах для релизного коммита `dfb355190e6b006c13f75a10f308ba6c43880e1a`.
- [Release workflow](https://github.com/Manannikov-Nikita/miracle/actions/runs/43102648604) повторил матрицу проверок и опубликовал три архива, их `.sha256` и `install.sh` из этого коммита.

На каждой платформе прошли тесты, production build, проверка лицензий, сборка архива с закреплённым Node 24.22.2, установка и lifecycle с bundled runtime, backup/restore и переход с опубликованной 0.11.1 через CLI. Необязательная задача `connectors` с реальными ClickHouse/Trino была пропущена; её запуск не входит в подтверждённый результат CI.

## Публичная установка и обновление

12 ноября 2026 года в 00:32:41 МСК завершена проверка на macOS ARM64 с настоящими загрузками из GitHub Release в изолированные каталоги:

- Чистая установка через публичный `latest/download/install.sh` установила 0.12.0 с Node 24.22.2. Профили оболочки не изменились; запуск и повторный запуск прошли, рабочая область и доска сохранились после перезапуска. SQLite остался на схеме 8.
- Публичный установщик 0.11.1 установил предыдущую версию. Её `miracle update --check` нашёл 0.12.0, сохранив PID работающего проекта.
- Настоящий сетевой `miracle update` обновил 0.11.1 до 0.12.0. Сохранились рабочая область, доска, ключ шифрования, порт и схема 8. Повторные `update --check` и `update` на актуальной версии не меняли данные и PID.
- После проверки оба тестовых проекта остановлены, временные установки и данные удалены; очистка подтверждена.

## Границы подтверждения

Реальные платные запросы Codex/Claude, Windows/WSL, мобильный интерфейс и внешние корпоративные ClickHouse/Trino в этом цикле не проверялись. Адаптеры Codex/Claude и сетевые состояния проверены автоматическими тестами с контролируемыми провайдерами; это не заменяет проверку живого сервиса.
