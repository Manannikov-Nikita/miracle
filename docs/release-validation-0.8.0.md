# Проверка Miracle 0.8.0

Состояние на **6 ноября 2026 года**: локальный кандидат проверен; публикация и проверка публичных архивов выполняются отдельно. До их завершения опубликованным выпуском остаётся [0.7.0](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.7.0).

## Состав выпуска

Презентации со слайдами 16:9, независимые панели редактора/доски/презентации, копирование блоков и сохранённых SQL-результатов, полноэкранный показ. Добавлены фигуры и текст с настройками оформления, выравнивание по краям слайда и перестановка слайдов во время перетаскивания. В агенте появились адресные ссылки на открытые вкладки, контекст презентаций и слайдов, блокировки затрагиваемых объектов и объединение независимых изменений. Проводник стал компактнее и получил изменение ширины. Локальные операции Git проекта доступны в левой панели. Подробности: [заметки выпуска](../.github/release-notes/0.8.0.md).

## Проверки исходников

- Node.js **24.22.2**. Свежий полный `npm test`: **158 файлов, 2032 теста прошли**. Журнал: `/tmp/miracle-080-tests.log`.
- `npm run build`: обе проверки TypeScript, клиент Vite и сервер собраны. Сохраняется предупреждение о крупном JS bundle (около 6.8 MB до gzip). Журнал: `/tmp/miracle-080-build.log`.
- `npm run notices`: 316 пакетов; `THIRD_PARTY_NOTICES.md` не изменился. `git diff --check` прошёл. Версия package.json и двух записей package-lock.json — 0.8.0.
- Независимая проверка схемы презентаций, совместимости обычных досок, слияния изменений, конфликтов удаления слайда, блокировок, MCP и фиксации назначения асинхронных операций не нашла блокеров. Дополнительный прогон шести файлов: 58 тестов прошли.
- Git проверен на временных настоящих репозиториях: создание/переключение веток, выборочный коммит, сохранение постороннего staging, защита незавершённых операций и служебных данных, фиксация ревизии и блокировка конкурирующих записей.

## Проверки интерфейса

В ходе разработки в @Browser проверялись презентации, изменение раскладки и размеров, перенос блоков, показ и выход, фигуры/текст, выбор назначения SQL, подсветка работы агента и боковой Git. Для Git использовался отдельный временный проект; в основной тестовой среде подтверждены перенос кнопки в левую панель и её доступность при скрытом редакторе. Несохранённые вкладки защищены при переключении ветки. Локальные тестовые документы, датасеты, скриншоты и базы не входят в архив выпуска.

## Локальный установочный архив

Архив macOS ARM64 собран штатным `scripts/build-release.mjs` с проверкой SHA-256 Node runtime. `tests/local-install-smoke.mjs` прошёл: установка и переустановка без системного Node, запуск нескольких временных проектов, свободные порты, Trino HTTPS CA, приватные файлы состояния и backup/restore. Проверены четыре обновления опубликованных 0.2.0/0.2.1 до кандидата 0.8.0 с обычными и нестандартными путями: сохранение ключа, секретов, SQL, доски, результатов, прежнего origin и резервных копий; ошибочная контрольная сумма отклоняется. Журналы: `/tmp/miracle-080-archive.log`, `/tmp/miracle-080-install.log`, `/tmp/miracle-080-upgrades.log`. Это проверка локального кандидата, не публичных архивов.

## Ограничения проверки

Полная проверка реальных ClickHouse/Trino/TLS, реального Claude CLI, Windows/WSL-хоста и мобильного браузера в этом прогоне не выполнялась. Linux CI не заменяет WSL-хост. Экспорт презентаций в PDF/PPTX не входит в версию. Для панели Git нужен Git в PATH; приложение запускается без него. Публикация, четыре нативные платформы и публичная установка будут отмечены ниже только по фактическим результатам.
