# Проверка Miracle 0.8.0

Состояние на **6 ноября 2026 года**: [Miracle 0.8.0 опубликован](https://github.com/Manannikov-Nikita/miracle/releases/tag/v0.8.0). Все четыре платформы прошли CI; публичная установка и обновления подтверждены. Merge-коммит и тег: `6c1cf222101e821494e2d91e4e2634937f99291b`. Происхождение архивов, SHA-256 и результаты публикации: [сводный отчёт](release-validation.md). Ниже сохранены функциональные проверки выпуска.

## Состав выпуска

Презентации со слайдами 16:9, независимые панели редактора/доски/презентации, копирование блоков и сохранённых SQL-результатов, полноэкранный показ. Добавлены фигуры и текст с настройками оформления, выравнивание по краям слайда и перестановка слайдов во время перетаскивания. В агенте появились адресные ссылки на открытые вкладки, контекст презентаций и слайдов, блокировки затрагиваемых объектов и объединение независимых изменений. Проводник стал компактнее и получил изменение ширины. Локальные операции Git проекта доступны в левой панели. Подробности: [заметки выпуска](../.github/release-notes/0.8.0.md).

## Проверки исходников

- Node.js **24.22.2**. Свежий полный `npm test`: **158 файлов, 2032 теста прошли**. Журнал: `.local/release-0.8.0/release-tests.log`.
- `npm run build`: обе проверки TypeScript, клиент Vite и сервер собраны. Сохраняется предупреждение о крупном JS bundle (около 6.8 MB до gzip). Журнал: `.local/release-0.8.0/release-build.log`.
- `npm run notices`: 316 пакетов; `THIRD_PARTY_NOTICES.md` не изменился. `git diff --check` прошёл. Версия package.json и двух записей package-lock.json — 0.8.0.
- Независимая проверка схемы презентаций, совместимости обычных досок, слияния изменений, конфликтов удаления слайда, блокировок, MCP и фиксации назначения асинхронных операций не нашла блокеров. Дополнительный прогон шести файлов: 58 тестов прошли.
- Git проверен на временных настоящих репозиториях: создание/переключение веток, выборочный коммит, сохранение постороннего staging, защита незавершённых операций и служебных данных, фиксация ревизии и блокировка конкурирующих записей.

## Проверки интерфейса

В ходе разработки в @Browser проверялись презентации, изменение раскладки и размеров, перенос блоков, показ и выход, фигуры/текст, выбор назначения SQL, подсветка работы агента и боковой Git. Для Git использовался отдельный временный проект; в основной тестовой среде подтверждены перенос кнопки в левую панель и её доступность при скрытом редакторе. Несохранённые вкладки защищены при переключении ветки. Локальные тестовые документы, датасеты, скриншоты и базы не входят в архив выпуска.

## Локальный установочный архив

Архив macOS ARM64 собран штатным `scripts/build-release.mjs` с проверкой SHA-256 Node runtime. `tests/local-install-smoke.mjs` прошёл: установка и переустановка без системного Node, запуск нескольких временных проектов, свободные порты, Trino HTTPS CA, приватные файлы состояния и backup/restore. Проверены четыре обновления опубликованных 0.2.0/0.2.1 до кандидата 0.8.0 с обычными и нестандартными путями: сохранение ключа, секретов, SQL, доски, результатов, прежнего origin и резервных копий; ошибочная контрольная сумма отклоняется. Журналы: `.local/release-0.8.0/release-archive.log`, `.local/release-0.8.0/release-install.log`, `.local/release-0.8.0/release-upgrades.log`. Это проверка локального кандидата, не публичных архивов.

## Проверки публикации

[PR CI 42289611944](https://github.com/Manannikov-Nikita/miracle/actions/runs/42289611944) и [release workflow 42291226496](https://github.com/Manannikov-Nikita/miracle/actions/runs/42291226496) завершились успешно на macOS ARM64/x64 и Linux ARM64/x64. Optional connectors пропущены. Из release workflow опубликованы четыре архива, четыре контрольные суммы и фиксированный `install.sh`.

Все девять файлов скачаны без авторизации; размеры и SHA-256 совпали с metadata GitHub и опубликованными контрольными суммами. На macOS ARM64 прошли публичная чистая/повторная установка, четыре онлайн-перехода с 0.2.0/0.2.1 и CLI-обновление 0.7.0 → 0.8.0 с сохранением данных; схема SQLite осталась 5. Повторные `update --check` и `update` на 0.8.0 сохранили работающий процесс и данные.

Через API опубликованной сборки подтверждено сохранение после перезапуска метаданных слайда, оформления текста, фигуры, стрелки и SQL-снимка презентации, а также фильтрация документов по типу. Сохранились свободная стрелка с оформлением и исходники/данные кастомного графика. Эти проверки не подтверждают браузерную отрисовку: статус рендера кастомного графика остался `not_observed`.

Все три этапа публичной проверки завершились с кодом 0; последнее завершение — **6 ноября 2026 года, 20:59:00 UTC**. `.local/release-0.8.0/public-summary.json` содержит `passed: true`; хеши и размеры находятся в `.local/release-0.8.0/public/verification.json`. Подробности: [сводный отчёт](release-validation.md).

## Ограничения проверки

Полная проверка реальных ClickHouse/Trino/TLS, реального Claude CLI, Windows/WSL-хоста и мобильного браузера в этом прогоне не выполнялась. Linux CI не заменяет WSL-хост. Экспорт презентаций в PDF/PPTX не входит в версию. Для панели Git нужен Git в PATH или путь `MIRACLE_GIT_BINARY`; приложение запускается без него.

Сохраняется прежнее предупреждение **low** [GHSA-238p-pmpm-9mq7](https://github.com/advisories/GHSA-238p-pmpm-9mq7) для вложенного KaTeX 0.16.47 в `micromark-extension-math`. Прямая зависимость KaTeX 0.19.1 не устраняет предупреждение для вложенной копии; возможность эксплуатации в Miracle отдельно не исследовалась.
